# مربع حوار التنبيه

مربع حوار التأكيد هو `Dialog` يتضمن زوج أزرار «إلغاء / تأكيد» مدمجًا، ويُستخدم للتأكيد الثانوي قبل العمليات غير القابلة للعكس. تُعرض المعاينة أدناه مباشرةً بواسطة محرك pingo، وتتبع مظهر الموقع الفاتح/الداكن.

:::preview alert-dialog-basic
:::

## الاستخدام

```tsx
import { AlertDialog } from "@dopejs/pingo-ui";

root.render(
  <AlertDialog
    open={open}
    onOpenChange={(next) => setOpen(next)}
    title="تأكيد الخروج؟"
    description="ستُفقد التعديلات غير المحفوظة."
    onCancel={() => {}}
    onAction={() => quit()}
  >
    {null}
  </AlertDialog>,
);
```

كما هو الحال مع `Dialog`، تملأ الطبقة العائمة الحاوية الأصل الخاصة بها، لذا ثبّتها قرب العقدة الجذرية. لاحظ أن `children` موروثة من `DialogProps` ولا تزال مطلوبة، لكن بنية العنوان/الوصف/الأزرار المدمجة داخل المكوّن ستتجاوزها، لذا يكفي تمرير `null`. النقر على زر الإلغاء أو التأكيد يشغّل الاستدعاء المقابل أولًا، ثم يطلب الإغلاق عبر `onOpenChange(false)`؛ والنقر على الخلفية المعتمة يغلق أيضًا.

## الخصائص

يرث `DialogProps` (مثل `open` و`onOpenChange` و`children` و`className`)، بالإضافة إلى:

| Prop          | النوع        | القيمة الافتراضية | الوصف                         |
| ------------- | ------------ | ----------------- | ----------------------------- |
| `title`       | `string`     | —                 | العنوان (مطلوب)               |
| `description` | `string`     | —                 | وصف إضافي                     |
| `cancelLabel` | `string`     | `"إلغاء"`         | نص زر الإلغاء                 |
| `actionLabel` | `string`     | `"تأكيد"`         | نص زر التأكيد                 |
| `onCancel`    | `() => void` | —                 | استدعاء الإلغاء (يُغلق بعده)  |
| `onAction`    | `() => void` | —                 | استدعاء التأكيد (يُغلق بعده)  |
| `destructive` | `boolean`    | `false`           | استخدام لون الخطر لزر التأكيد |

## إمكانية الوصول

يتمتع بدلالات `dialog`؛ وزرا الإلغاء والتأكيد مسجّلان في حلقة التنقل بـ Tab، فلا يعلق مستخدمو لوحة المفاتيح داخل مربع الحوار.
