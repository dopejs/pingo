# Alert

يُستخدم Alert لعرض رسائل تنبيه تحتاج لانتباه المستخدم دون مقاطعة تدفق العمل. المعاينة أدناه تُرسم مباشرة بواسطة محرك pingo وتتبع تبديل السمة الفاتحة/الداكنة للموقع.

:::preview alert-basic
:::

## الاستخدام

```tsx
import { createElement } from "@dopejs/pingo";
import { Alert } from "@dopejs/pingo-ui";

root.render(
  createElement(Alert, {
    title: "تنبيه",
    children: "تم حفظ إعداداتك تلقائيًا.",
  }),
);
```

## أمثلة

### تنبيه تحذيري

يُستخدم `variant="destructive"` في سيناريوهات الخطأ أو الفشل: يتحول الحد والعنوان إلى ألوان تحذيرية، بينما يبقى نص الوصف بلون المقدمة العادي لضمان سهولة القراءة.

```tsx
createElement(Alert, {
  title: "فشل المزامنة",
  variant: "destructive",
  children: "يرجى التحقق من اتصال الشبكة ثم إعادة المحاولة.",
});
```

## Props

| Prop        | النوع                        | القيمة الافتراضية | الوصف                     |
| ----------- | ---------------------------- | ----------------- | ------------------------- |
| `title`     | `string`                     | —                 | العنوان (مطلوب)           |
| `children`  | `string`                     | —                 | النص الوصفي (مطلوب)       |
| `variant`   | `"default" \| "destructive"` | `"default"`       | النمط البصري              |
| `className` | `string`                     | —                 | يُضاف بعد اسم فئة المكوّن |

## إمكانية الوصول

Alert عبارة عن كتلة نصية ثابتة لا تخطف التركيز؛ استخدم `title` موجزًا لتلخيص النتيجة وضع التفاصيل في الوصف. في السيناريوهات التي تتطلب تأكيدًا أو إجراءً من المستخدم، استخدم `AlertDialog` بدلاً من ذلك.
