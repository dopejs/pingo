# Breadcrumb

شريط تنقل متسلسل: كل عنصر عدا العنصر الأخير هو رابط قابل للنقر، والعنصر الأخير يمثل الصفحة الحالية — لا يُعرض كرابط، ولا يوفر للتقنيات المساعدة إجراء "الانتقال إلى الموقع الحالي". المعاينة أدناه تُرسم لحظيًا بواسطة محرك pingo — يمكنك النقر على العناصر السابقة، وتفعيلها بلوحة المفاتيح، وتبديل الوضع الفاتح/الداكن وفقًا لسمة الموقع.

:::

## الاستخدام

```tsx
import { Breadcrumb } from "@dopejs/pingo-ui";

root.render(
  <Breadcrumb
    items={[
      { label: "الرئيسية", onNavigate: () => navigate("/") },
      { label: "المكونات", onNavigate: () => navigate("/components") },
      { label: "Breadcrumb" }, // العنصر الأخير هو الصفحة الحالية، لا حاجة لـ onNavigate
    ]}
  />,
);
```

## أمثلة

### فاصل مخصص

`separator` قيمته الافتراضية هي `/`، ويمكن استبداله بأي رمز نصي (قبل اكتمال مجموعة الأيقونات يكون الفاصل محرفًا نصيًا):

## Props

### BreadcrumbProps

| Prop        | النوع                       | القيمة الافتراضية | الوصف                                                                |
| ----------- | --------------------------- | ----------------- | -------------------------------------------------------------------- |
| `items`     | `readonly BreadcrumbItem[]` | —                 | عناصر شريط التنقل المتسلسل، يُعامل العنصر الأخير كصفحة حالية (مطلوب) |
| `separator` | `string`                    | `"/"`             | الفاصل بين العناصر                                                   |
| `className` | `string`                    | —                 | يُلحق بعد اسم فئة المكوّن                                            |

### BreadcrumbItem

| الحقل        | النوع        | القيمة الافتراضية | الوصف                                                                                                                |
| ------------ | ------------ | ----------------- | -------------------------------------------------------------------------------------------------------------------- |
| `label`      | `string`     | —                 | نص العنصر (مطلوب)                                                                                                    |
| `onNavigate` | `() => void` | —                 | رد فعل النقر؛ عند عدم توفيره لا يحمل العنصر أي سلوك تفعيل (العنصر الأخير يُعامل أصلًا كصفحة حالية، فلا حاجة لتوفيره) |

## إمكانية الوصول

شريط التنقل المتسلسل ككل له دلالة `navigation` واسمه "breadcrumb"؛ والعناصر القابلة للنقر لها دلالة link، وتدعم التفعيل بلوحة المفاتيح عبر `Enter` / `Space`، ويتم التركيز عليها قبل النقر. تُعرض الصفحة الحالية كنص خالص مع قيمة دلالية `current`، ولا يعتبرها قارئ الشاشة رابطًا قابلًا للانتقال. للمزيد راجع [دليل إمكانية الوصول](/guide/accessibility).
