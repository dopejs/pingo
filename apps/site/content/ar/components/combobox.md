# Combobox

يربط صندوق التحرير المشترك زنادًا يعرض القيمة المحددة بقائمة خيارات قابلة للبحث. المعاينة أدناه تُعرض مباشرة بواسطة محرك pingo — القائمة مفتوحة، يمكنك الكتابة للتصفية، والتنقل بأسهم لوحة المفاتيح، وتبديل الوضع الفاتح والداكن تبعًا لسمة الموقع.

:::preview combobox-basic
:::

## الاستخدام

```tsx
import { Combobox } from "@dopejs/pingo-ui";

root.render(
  <Combobox
    items={[
      { value: "next", label: "Next.js" },
      { value: "remix", label: "Remix" },
      { value: "astro", label: "Astro" },
    ]}
    placeholder="اختر إطار عمل"
    onValueChange={(value) => console.log(value)}
  />,
);
```

`items` هي مصفوفة من `{ value, label }`؛ التصفية عبارة عن مطابقة جزئية غير حساسة لحالة الأحرف على `label` — تعمّدنا عدم إجراء فرز ضبابي، فالفرز الخاطئ أسوأ من غياب الفرز. بعد الاختيار تُطوى القائمة تلقائيًا، وتُمسح كلمة البحث عند **الإغلاق**، حتى لا تجد نفسك أمام كلمة تصفية قديمة منسية عند إعادة الفتح.

## أمثلة

### مُتحكَّم به

يمكن التحكم في `value` / `onValueChange` وكذلك `open` / `onOpenChange`؛ عند غيابها يدير المكوِّن حالته ذاتيًا عبر `defaultValue` / `defaultOpen`.

### حالة فارغة

`emptyLabel` يخصص نص التلميح عندما لا تُسفر التصفية عن أي نتيجة.

## Props

| Prop            | النوع                                         | الافتراضي           | الوصف                                                            |
| --------------- | --------------------------------------------- | ------------------- | ---------------------------------------------------------------- |
| `items`         | `readonly { value: string; label: string }[]` | —                   | قائمة الخيارات (مطلوبة)                                          |
| `value`         | `string`                                      | —                   | القيمة المحددة المُتحكَّم بها                                    |
| `defaultValue`  | `string`                                      | —                   | القيمة المحددة الابتدائية غير المُتحكَّم بها                     |
| `onValueChange` | `(value: string) => void`                     | —                   | استدعاء عند تغيّر الاختيار (تُطوى القائمة تلقائيًا بعد الاختيار) |
| `open`          | `boolean`                                     | —                   | حالة الفتح والإغلاق المُتحكَّم بها                               |
| `defaultOpen`   | `boolean`                                     | `false`             | حالة الفتح الابتدائية غير المُتحكَّم بها                         |
| `onOpenChange`  | `(open: boolean) => void`                     | —                   | استدعاء عند تغيّر حالة الفتح                                     |
| `placeholder`   | `string`                                      | `"الرجاء الاختيار"` | نص placeholder على الزناد عند عدم وجود تحديد                     |
| `emptyLabel`    | `string`                                      | —                   | التلميح عند غياب نتائج التصفية                                   |
| `className`     | `string`                                      | —                   | يُضاف بعد اسم فئة المكوِّن                                       |

## إمكانية الوصول

الزناد يحمل دلالات button ويتنقل بين `expanded` / `collapsed`. عند فتح القائمة ينتقل التركيز إلى حقل البحث، وتحرّك أسهم لوحة المفاتيح التمييز، ويؤدي Enter إلى الاختيار والإغلاق؛ بعد الإغلاق يعود التركيز إلى الزناد.
