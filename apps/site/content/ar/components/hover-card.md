# بطاقة التمرير

توسّع بطاقة التمرير بطاقة محتوى غنية عند التمرير (أو التركيز) على العنصر المُطلق — وتحمل معلومات أكثر من تلميح الأدوات، مثل معاينة ملف المستخدم. المعاينة أدناه تُعرض مباشرة بواسطة محرك pingo (معروضة بحالة `open` مضبوطة دائمًا للعرض)، وتتبع سمة الموقع للتبديل بين الفاتح والداكن.

:::preview hover-card-basic
:::

## الاستخدام

```tsx
import { HoverCard } from "@dopejs/pingo-ui";

root.render(
  <HoverCard
    openDelayMs={300}
    closeDelayMs={200}
    content={<text value="محرك عرض Canvas ومكتبة مكونات واجهة." />}
  >
    <text value="@pingo" />
  </HoverCard>,
);
```

لا تُغلق البطاقة عند التمرير فوق البطاقة نفسها بعد فتحها، لذا يمنح `closeDelayMs` المؤشر وقتًا لعبور الفجوة بين العنصر المُطلق والبطاقة. بتمرير `open` يمكنك التحول إلى الوضع المضبوط، وإدارة الحالة بنفسك عبر `onOpenChange`.

## الخصائص

| Prop           | النوع                     | القيمة الافتراضية | الوصف                            |
| -------------- | ------------------------- | ----------------- | -------------------------------- |
| `children`     | `PingoNode`               | —                 | العنصر المُطلق (مطلوب)           |
| `content`      | `PingoNode`               | —                 | محتوى البطاقة (مطلوب)            |
| `open`         | `boolean`                 | —                 | حالة الفتح والإغلاق المضبوطة     |
| `onOpenChange` | `(open: boolean) => void` | —                 | استدعاء عند تغير الفتح والإغلاق  |
| `openDelayMs`  | `number`                  | `300`             | تأخير الفتح (بالمللي ثانية)      |
| `closeDelayMs` | `number`                  | `200`             | تأخير الإغلاق (بالمللي ثانية)    |
| `className`    | `string`                  | —                 | يُضاف بعد اسم فئة حاوية الارتساء |

## إمكانية الوصول

يفتح العنصر المُطلق البطاقة عند التركيز أيضًا، وتُغلق عند فقدان التركيز، فلا يفقد مستخدمو لوحة المفاتيح المحتوى.
