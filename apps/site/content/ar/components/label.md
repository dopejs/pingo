# Label

تُستخدم التسمية لتوفير اسم مرئي لعناصر التحكم في النموذج. المعاينة أدناه يُنفذها محرك pingo في الوقت الفعلي، وتتبع سمة الموقع في التبديل بين الوضعين الفاتح والداكن.

:::preview label-basic
:::

## الاستخدام

```tsx
import { Input, Label } from "@dopejs/pingo-ui";

root.render(
  <container style={{ flexDirection: "column" }}>
    <Label>البريد الإلكتروني</Label>
    <container height={8} />
    <Input semanticLabel="البريد الإلكتروني" width={320} />
  </container>,
);
```

لا توجد خاصية `gap` في pingo، لذا تُنفَّذ المسافة بين التسمية وعنصر التحكم باستخدام حاوية ذات حجم ثابت.

## أمثلة

### الاسم الدلالي

لا يوجد بعد ربط لعناصر التحكم في pingo، لذا يعتمد الربط بين التسمية وعنصر التحكم على الاصطلاح: مرِّر إلى عنصر التحكم `semanticLabel` مطابقًا للتسمية، ليتمكن قارئ الشاشة من قراءة الاسم نفسه.

## Props

| Prop            | النوع    | القيمة الافتراضية | الوصف                                                                      |
| --------------- | -------- | ----------------- | -------------------------------------------------------------------------- |
| `children`      | `string` | —                 | نص التسمية (إلزامي)                                                        |
| `className`     | `string` | —                 | يُضاف بعد اسم فئة المكوّن                                                  |
| `semanticLabel` | `string` | —                 | يتجاوز الاسم الخاص بإمكانية الوصول؛ يُستخدم نص التسمية افتراضيًا عند غيابه |

## إمكانية الوصول

لا توجد بعد آلية لربط التسمية بعنصر التحكم في pingo، فالتسمية مجرد نص منسَّق. عيِّن دائمًا `semanticLabel` على عنصر التحكم المقابل لضمان ألا يعتمد الاسم الخاص بإمكانية الوصول على التجاور البصري.
