# قابل لتغيير الحجم

يقسّم المكوّن قابل لتغيير الحجم الحاوية إلى لوحتين، ويمكن سحب مقبض التقسيم بينهما لضبط النسبة، كما يدعم الضبط الدقيق بلوحة المفاتيح. المعاينة أدناه تُعرض مباشرةً بواسطة محرك pingo — جرّب سحب المقبض.

:::preview resizable-basic
:::

## الاستخدام

```tsx
import { Resizable } from "@dopejs/pingo-ui";

root.render(<Resizable defaultSplit={0.4} first={sidebar} second={content} />);
```

يبلغ عرض المكوّن وارتفاعه 100% من الحاوية الأب، ويتطلب حاوية أب ذات أبعاد محددة. يدعم كلاً من الاستخدام غير المُتحكَّم به (`defaultSplit`) والاستخدام المُتحكَّم به (`split` + `onSplitChange`).

## أمثلة

### الاتجاه العمودي

مرّر `direction: "column"` للتبديل إلى التقسيم العلوي-السفلي، حيث يصبح المقبض أفقيًا.

:::preview resizable-vertical
:::

## Props

| Prop            | النوع                     | القيمة الافتراضية | الوصف                                     |
| --------------- | ------------------------- | ----------------- | ----------------------------------------- |
| `first`         | `PingoNode`               | —                 | محتوى اللوحة الأولى (مطلوب)               |
| `second`        | `PingoNode`               | —                 | محتوى اللوحة الثانية (مطلوب)              |
| `split`         | `number`                  | —                 | مُتحكَّم به: نسبة اللوحة الأولى، `[0, 1]` |
| `defaultSplit`  | `number`                  | `0.5`             | غير مُتحكَّم به: النسبة الابتدائية        |
| `onSplitChange` | `(split: number) => void` | —                 | استدعاء عند تغيّر النسبة                  |
| `direction`     | `"row" \| "column"`       | `"row"`           | اتجاه التقسيم                             |
| `minSplit`      | `number`                  | `0.1`             | الحد الأدنى للنسبة (تثبيت الحد الأدنى)    |
| `maxSplit`      | `number`                  | `0.9`             | الحد الأقصى للنسبة (تثبيت الحد الأقصى)    |
| `disabled`      | `boolean`                 | `false`           | تعطيل تفاعل المقبض                        |
| `className`     | `string`                  | —                 | يُضاف بعد اسم فئة المكوّن                 |

## إمكانية الوصول

يمتلك المقبض دلالة الفاصل، ويكشف للتّقنيات المساعدة النسبة الحالية (كنسبة مئوية). بعد التركيز على المقبض يمكن استخدام مفاتيح الأسهم للضبط الدقيق بخطوة 2%: اليسار/اليمين للتخطيط الأفقي، والأعلى/الأسفل للتخطيط العمودي.
