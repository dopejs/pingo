# Tooltip

يعرض Tooltip نصًا توضيحيًا قصيرًا عند تحويم المؤشر، ويكون مثبتًا افتراضيًا فوق الهدف. تُعرض المعاينة التالية مباشرةً بواسطة محرك pingo — مرّر المؤشر فوق الزر لرؤية الفقاعة، وهي تتبع تلقائيًا مظهر الموقع الفاتح أو الداكن.

:::preview tooltip-basic
:::

## الاستخدام

```tsx
import { Button, Tooltip } from "@dopejs/pingo-ui";

root.render(
  <Tooltip content="حفظ إلى السحابة">
    <Button onPress={() => save()}>حفظ</Button>
  </Tooltip>,
);
```

يعمل Tooltip بدخول المؤشر وخروجه (`pointerenter` / `pointerleave`) دون خاصيات مُتحكَّم بها؛ عند العرض/الرسم الثابت يظهر عنصر التفعيل فقط، وتظهر الفقاعة عند التحويم.

## الخصائص

| Prop        | النوع       | القيمة الافتراضية | الوصف                                 |
| ----------- | ----------- | ----------------- | ------------------------------------- |
| `content`   | `string`    | —                 | نص الفقاعة (مطلوب)                    |
| `children`  | `PingoNode` | —                 | عنصر التفعيل (مطلوب)                  |
| `className` | `string`    | —                 | يُضاف بعد اسم فئة حاوية نقطة الارتساء |

## إمكانية الوصول

تتمتع الفقاعة بدلالات tooltip. يظهر Tooltip عند التحويم فقط، ولا يستجيب لتركيز لوحة المفاتيح؛ لا تضع المعلومات المهمة داخل Tooltip فقط.
