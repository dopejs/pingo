## البدء في 30 ثانية

```sh
pnpm add @dopejs/pingo
```

```ts
import { createElement, createHostedCanvasRoot } from "@dopejs/pingo";

const root = await createHostedCanvasRoot(document.querySelector("canvas")!);

root.render(
  createElement("virtualList", {
    width: 480,
    height: 640,
    itemCount: 1_000_000,
    estimatedItemHeight: 32,
    renderItem: (index) => createElement("text", { value: `السطر ${index}` }),
  }),
);
```

مليون سطر لن تُجسَّد على جانب الغلاف، وعملية التمرير لا تستدعي شجرة المكونات — حساب النوافذ وبناء العناصر يقعان داخل النواة.

## ما لا يفعله

Pingo محرك عرض، وليس متصفحًا. **لا يفعل** SSR/HTML للشاشة الأولى، ولا توافق CSS العام (نموذج الصندوق، التتالي، المحددات)،
ولا طبقات تكييف للتطبيقات المصغرة أو المنصات الأصلية، ولا دلالات النصوص المنسقة على مستوى الأعمال (التعاون، الصيغ الرياضية، أوامر Markdown).

المحرك **يمتلك فعلًا** المؤشر والتحديد وIME والحافظة والتراجع والإعادة وأوليات النص القابل للتحرير — وهذه لن تُدفع مرة أخرى إلى طبقة الأعمال
لتُركب بعناصر DOM.

أداء الأجهزة الحقيقية وطرق الإدخال الفعلية وقارئات الشاشة ومصفوفة استهلاك الوسائط للطاقة تنتمي إلى جمع أهلية المنصة وتُتبع بشكل منفصل؛
والتنقل البصري ثنائي الاتجاه وتفعيل خلفية WebGPU افتراضيًا ما يزالان [من البنود المؤجلة الموثقة](https://github.com/dopejs/pingo/blob/main/docs/plan.md).
