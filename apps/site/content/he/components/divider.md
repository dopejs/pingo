# Divider

קווי הפרדה מספקים קיבוץ ויזואלי בין תכנים. התצוגה המקדימה שלהלן מרונדרת בזמן אמת על ידי מנוע pingo ועוקבת אחר ערכת הנושא של האתר במעבר בין מצב בהיר לכהה.

:::preview divider-horizontal
:::

## שימוש

```tsx
import { createElement } from "@dopejs/pingo";
import { Divider } from "@dopejs/pingo-ui";

root.render(createElement(Divider, {}));
```

## דוגמאות

### קו הפרדה אנכי

העברת `orientation: "vertical"` מניבה קו הפרדה אנכי. גובהו של קו הפרדה אנכי הוא 100% מגובה רכיב האב, ולכן על רכיב האב להיות בעל גובה מוגדר.

:::preview divider-vertical
:::

## Props

| Prop          | סוג                          | ברירת מחדל     | תיאור                         |
| ------------- | ---------------------------- | -------------- | ----------------------------- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | כיוון קו ההפרדה               |
| `className`   | `string`                     | —              | מצורף לאחר שם המחלקה של הרכיב |

רוחבו של קו הפרדה אופקי הוא 100% מרוחב רכיב האב וגובהו 1px; גובהו של קו הפרדה אנכי הוא 100% מגובה רכיב האב ורוחבו 1px.

## נגישות

Divider הוא אלמנט ויזואלי בלבד, אינו נושא תפקיד סמנטי, וטכנולוגיות מסייעות יתעלמו ממנו; יש לבטא קיבוץ תכנים באמצעות מבנים סמנטיים כגון כותרות.
