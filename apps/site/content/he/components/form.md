# Form

`Form` הוא מיכל הטופס, ו-`FormField` מרכיב תווית, פקד ומידע שגיאה/תיאור לשדה אחד. התצוגה המקדימה שלהלן מרונדרת בזמן אמת על ידי מנוע pingo — אפשר ממש לערוך את שדות הקלט בתצוגה, והם עוקבים אחרי מעבר הנושא של האתר בין בהיר לכהה.

:::preview form-basic
:::

## שימוש

```tsx
import { Form, FormField, Input } from "@dopejs/pingo-ui";

root.render(
  <Form>
    <FormField label="אימייל" required error={emailError}>
      <Input semanticLabel="אימייל" onValueChange={(value) => validate(value)} />
    </FormField>
  </Form>,
);
```

האימות אינו בתוך הרכיב: מתי לאמת, איזו שגיאה להציג ואיך לחבר בין רכיבים הם החלטות מוצר. הקורא מחזיק את הכללים ומעביר `error`, והרכיב אחראי רק על פריסה, סמנטיקה ומיקומי מידע.

## דוגמאות

### שגיאה ותיאור

כאשר קיים `error`, השדה מסומן כלא תקין, והטקסט **מחליף** את טקסט התיאור — אם אחת משתי שורות ההנחיה היא הודעת כשל, השורה השנייה תטשטש אותה. `required` מוסיף סימון `*` אחרי התווית.

## Props

### Form

| Prop        | טיפוס       | ברירת מחדל | תיאור                         |
| ----------- | ----------- | ---------- | ----------------------------- |
| `children`  | `PingoNode` | —          | תוכן הטופס (חובה)             |
| `className` | `string`    | —          | מצורף אחרי שם המחלקה של הרכיב |

### FormField

| Prop          | טיפוס       | ברירת מחדל | תיאור                                                             |
| ------------- | ----------- | ---------- | ----------------------------------------------------------------- |
| `label`       | `string`    | —          | תווית השדה (חובה)                                                 |
| `children`    | `PingoNode` | —          | פקד השדה (חובה)                                                   |
| `error`       | `string`    | —          | הודעת שגיאה; כשהיא קיימת מסמנת את השדה כלא תקין ומחליפה את התיאור |
| `description` | `string`    | —          | טקסט תיאור מסייע                                                  |
| `required`    | `boolean`   | `false`    | סימון חובה, מוסיף `*` אחרי התווית                                 |
| `className`   | `string`    | —          | מצורף אחרי שם המחלקה של הרכיב                                     |

## נגישות

ל-`Form` יש תפקיד סמנטי `form`; ל-`FormField` יש סמנטיקה `group` והוא נקרא על שם התווית, וכאשר אינו תקין הערך הסמנטי הוא `invalid`. הסימון הסמנטי מוצמד לקבוצה ולא לפקד — הפקד שייך לקורא, והקבוצה היא האלמנט היחיד שמובטח קיומו.
