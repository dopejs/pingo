# Input OTP

קלט קוד אימות חד-פעמי, המורכב ממספר תאים באורך קבוע. התצוגה המקדימה שלהלן מרונדרת בזמן אמת על ידי מנוע pingo — ניתן להקליד ספרות תא-אחר-תא, להדביק קוד מלא, ולעבור בין מצב בהיר לכהה בהתאם לערכת הנושא של האתר.

:::preview input-otp-basic
:::

## שימוש

```tsx
import { createElement } from "@dopejs/pingo";
import { InputOTP } from "@dopejs/pingo-ui";

root.render(
  createElement(InputOTP, {
    length: 6,
    semanticLabel: "קוד אימות חד-פעמי",
    onValueChange: (value) => console.log(value),
    onComplete: (code) => verify(code),
  }),
);
```

הערך הפנימי הוא **מחרוזת באורך קבוע המרופדת ברווחים**: רווח מייצג תא ריק. `onValueChange` מקבל בדיוק את הערך המרופד הזה; `onComplete` מופעל פעם אחת כאשר כל התאים מלאים, ומקבל את קוד האימות המלא ללא רווחים. הדבקה נחשבת כמילוי מקטע שלם החל מהתא הנוכחי, ומחיקה מנקה רק את התא הנוכחי מבלי להזיז שמאלה את הספרות הבאות.

## דוגמאות

### אורך

`length` קובע את מספר התאים (ברירת מחדל 6). כל תא משתמש במקלדת מספרית רכה (`inputMode: "numeric"`).

## Props

| Prop            | סוג                       | ברירת מחדל | תיאור                                                              |
| --------------- | ------------------------- | ---------- | ------------------------------------------------------------------ |
| `length`        | `number`                  | `6`        | מספר התאים                                                         |
| `value`         | `string`                  | —          | ערך נוכחי מבוקר (מרופד ברווחים)                                    |
| `defaultValue`  | `string`                  | —          | ערך התחלתי לא מבוקר                                                |
| `onValueChange` | `(value: string) => void` | —          | קריאה חוזרת בשינוי ערך, הערך הוא מחרוזת באורך קבוע המרופדת ברווחים |
| `onComplete`    | `(value: string) => void` | —          | קריאה חוזרת כאשר הכל מלא, הערך הוא קוד האימות המלא ללא רווחים      |
| `disabled`      | `boolean`                 | `false`    | משבית את כל התאים                                                  |
| `semanticLabel` | `string`                  | —          | שם נגיש לקבוצה                                                     |
| `className`     | `string`                  | —          | מצורף לאחר שם המחלקה של הרכיב                                      |

## נגישות

הרכיב נושא תפקיד סמנטי `group`; כל תא מקבל אוטומטית שם נגיש בתבנית `מספר סידורי/סה"כ` (לדוגמה `3/6`), וניתן גם לתת שם לכל הקבוצה באמצעות `semanticLabel`.
