# Pagination

פקד פָּגִינַצְיָה: העמוד הנוכחי מודגש, רצף מספרי עמודים ארוך מקופל אוטומטית לאליפסיס, ובהגעה לעמוד הראשון/האחרון החץ המתאים מושבת. התצוגה המקדימה שלהלן מרונדרת בזמן אמת על ידי מנוע pingo — ניתן ללחוץ על מספרי עמודים וחצים כדי לדפדף, וכן לעקוב אחר מצב הנושא הבהיר/הכהה של האתר.

:::preview pagination-basic
:::

## שימוש

מספר העמוד הוא **מבוקר**: `page` מתחיל מ-1, והדפדוף מדווח באמצעות `onPageChange`, ועליך לכתוב אותו בחזרה.

```tsx
import { createElement, useSignal, type PingoNode } from "@dopejs/pingo";
import { Pagination } from "@dopejs/pingo-ui";

function PagedList(): PingoNode {
  const page = useSignal(1);
  return createElement(Pagination, {
    page: page.get(),
    pageCount: 12,
    onPageChange: (next) => page.set(next),
  });
}
```

## דוגמאות

### מצב קומפקטי

`siblingCount` קובע את מספר מספרי העמודים המוצגים משני צדי העמוד הנוכחי (לא כולל העמוד הראשון והאחרון, שמוצגים תמיד). כאשר מוגדר ל-`0`, נשמרים רק העמוד הראשון, האחרון והעמוד הנוכחי; בעמוד הראשון חץ הדף הקודם מושבת.

:::preview pagination-compact
:::

כלל הקיפול של רצף מספרי העמודים ממומש על ידי הפונקציה הטהורה המיוצאת `paginationRange(page, pageCount, siblingCount)`, וניתן להשתמש בה בנפרד לבדיקות.

## Props

| Prop            | סוג                      | ברירת מחדל | תיאור                                                                                 |
| --------------- | ------------------------ | ---------- | ------------------------------------------------------------------------------------- |
| `page`          | `number`                 | —          | העמוד הנוכחי, מתחיל מ-1 (חובה); ערך מחוץ לתחום יקוצר ל-`[1, pageCount]`               |
| `pageCount`     | `number`                 | —          | מספר העמודים הכולל (חובה); קטן מ-1 לא מרונדר אף מספר עמוד                             |
| `onPageChange`  | `(page: number) => void` | —          | קריאה חוזרת לדפדוף; לחיצה על העמוד הנוכחי או על יעד מחוץ לתחום לא תפעיל אותה          |
| `siblingCount`  | `number`                 | `1`        | מספר מספרי העמודים המוצגים מכל צד של העמוד הנוכחי                                     |
| `previousLabel` | `string`                 | —          | טקסט הדף הקודם השמור בטיפוס; בגרסה הנוכחית מרונדר כסמל, שדה זה עדיין לא משתתף ברינדור |
| `nextLabel`     | `string`                 | —          | טקסט הדף הבא השמור בטיפוס; בגרסה הנוכחית מרונדר כסמל, שדה זה עדיין לא משתתף ברינדור   |
| `className`     | `string`                 | —          | מצורף לאחר שם מחלקת הרכיב                                                             |

## נגישות

הפקד כולו הוא בעל סמנטיקת `navigation`; העמוד הנוכחי נושא ערך סמנטי `current`, שמות הנגישות של כפתורי הדפדוף קדימה/אחורה הם "previous page" / "next page", ובהגעה לקצה הם מושבתים ואינם מגיבים למצביע. במקלדת, `ArrowLeft` / `ArrowRight` מדפדפים מכל נקודת מיקוד בתוך הפקד. לפרטים נוספים ראו [מדריך הנגישות](/guide/accessibility).
