# Progress

Progress מציג התקדמות דטרמיניסטית באמצעות מסלול ממולא, למשל עבור הורדות, העלאות או משימות מרובות שלבים. התצוגה המקדימה שלהלן מרונדרת בזמן אמת על ידי מנוע pingo, ועוקבת אחר ערכת הנושא של האתר בהיר/כהה.

:::preview progress-basic
:::

## שימוש

```tsx
import { Progress } from "@dopejs/pingo-ui";

root.render(<Progress value={60} />);
```

רוחב המסלול יורש את מיכל האב. הצבת Progress בתוך מיכל ברוחב קבוע תשלוט באורך הפס:

```tsx
<container width={320}>
  <Progress value={60} />
</container>
```

## דוגמאות

### ערך מקסימלי מותאם אישית

ברירת המחדל של `max` היא 100. כאשר מועבר ערך, אחוז המילוי מחושב לפי `value / max`, ותמיד נצמד לטווח 0–100:

```tsx
<Progress value={3} max={10} /> // 30%
```

## Props

| Prop        | טיפוס    | ברירת מחדל | תיאור                                            |
| ----------- | -------- | ---------- | ------------------------------------------------ |
| `value`     | `number` | —          | ההתקדמות הנוכחית (חובה), ערכים מחוץ לטווח ייצמדו |
| `max`       | `number` | `100`      | הערך המקסימלי, מינימום יטופל כ-1                 |
| `className` | `string` | —          | מצורף לשם מחלקת הרכיב                            |

## נגישות

Progress הוא אלמנט ויזואלי בלבד, ללא תפקיד סמנטי מצורף. אם ההתקדמות קריטית להשלמת המשימה, יש לצרף טקסט תומך לצדו המציין את האחוז הנוכחי או את שם השלב.
