# Scroll Area

Scroll Area גולל תוכן ארוך מדי בתוך תצוגה בגודל קבוע, ומצייר פס גלילה התואם לערכת הנושא. התצוגה המקדימה שלהלן מרונדרת בזמן אמת על ידי מנוע pingo — נסו לגלול ברשימה.

:::preview scroll-area-basic
:::

## שימוש

```tsx
import { ScrollArea } from "@dopejs/pingo-ui";

root.render(
  <ScrollArea>
    {items.map((item) => (
      <text value={item} />
    ))}
  </ScrollArea>,
);
```

רוחב וגובה הרכיב הם 100% ממיכל האב, ונדרש מיכל אב בעל ממדים מוגדרים; פס הגלילה יופיע רק כאשר התוכן חורג מהתצוגה.

## Props

| Prop            | טיפוס       | ברירת מחדל | תיאור                                       |
| --------------- | ----------- | ---------- | ------------------------------------------- |
| `children`      | `PingoNode` | —          | תוכן הגלילה (חובה)                          |
| `hideScrollbar` | `boolean`   | `false`    | הסתרת פס הגלילה המצויר (יכולת הגלילה נשארת) |
| `className`     | `string`    | —          | מצורף לאחר שם המחלקה של הרכיב               |

## נגישות

התנהגות הגלילה מסופקת על ידי ליבת המנוע, והתצוגה נשארת ניתנת למיקוד ולתפעול גלילה במקלדת. פס הגלילה נגזר מהגאומטריה הנמדדת של התצוגה והתוכן; בעת גרירה מהירה, מחוון פס הגלילה עלול לפגר בפריים אחד.

להתנהגויות גלילה נוספות של המנוע ראו [מדריך הגלילה](/guide/scrolling).
