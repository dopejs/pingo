# StatCard

StatCard היא מולקולת מוצר ייחודית ל־pingo: אריח מדד המורכב מתווית, ערך, דלתא מול תקופה קודמת וטקסט הסבר. `trend` משפיע רק על צביעת הדלתא — `flat` נשאר אפור ניטרלי, כי למדד יציב אין טוב או רע. התצוגה המקדימה שלהלן מרונדרת בזמן אמת על ידי מנוע pingo ועוקבת אחר ערכת הנושא של האתר במעבר בין מצב בהיר לכהה.

:::preview statcard-basic
:::

יחסי ההרכבה עם רכיבי הבסיס של shadcn: StatCard היא מולקולת תצוגה עצמאית, משתמשת פנימית רק בפרימיטיבים Text/View ואינה שומרת מקום ל־slots; בפריסת לוח מחוונים נהוג להשתמש ב־container עם `flexDirection: "row"` כדי לסדר כמה כרטיסי StatCard בשורה, או לשלבם עם Card ו־Divider ליצירת מקטע דוח. עיצוב הערך (הפרדת אלפים, סימן מטבע) נעשה על ידי הצד הקורא; `value` ו־`delta` הם מחרוזות טהורות.

## שימוש

```tsx
import { StatCard } from "@dopejs/pingo-ui";

root.render(
  <StatCard
    label="הכנסות החודש"
    value="¥128,400"
    delta="+12.5%"
    trend="up"
    description="לעומת החודש הקודם"
  />,
);
```

## דוגמאות

### צביעת מגמה

`trend` מקבל `"up"` / `"down"` / `"flat"` וצובע את הדלתא בצבעי עלייה, ירידה וניטרליות בהתאמה; כאשר `trend` אינו מועבר, מתבצע טיפול כברירת מחדל כ־`flat`.

### ללא דלתא

כאשר משמיטים את `delta`, הערך תופס שורה לבדו ו־`trend` אינו משפיע; ניתן להשמיט גם את `description`.

```tsx
<StatCard label="מכשירים מקוונים" value="1,024" />
```

## Props

| Prop          | סוג                        | ברירת מחדל | תיאור                                        |
| ------------- | -------------------------- | ---------- | -------------------------------------------- |
| `label`       | `string`                   | —          | שם המדד (חובה)                               |
| `value`       | `string`                   | —          | ערך המדד, העיצוב באחריות הצד הקורא (חובה)    |
| `delta`       | `string`                   | —          | שינוי מול תקופה קודמת, כגון `+12.5%`         |
| `trend`       | `"up" \| "down" \| "flat"` | `"flat"`   | כיוון צביעת הדלתא, אינו משפיע על חלקים אחרים |
| `description` | `string`                   | —          | טקסט הסבר בתחתית, כגון תקופת ההשוואה         |
| `className`   | `string`                   | —          | מצורף לאחר שם המחלקה של הרכיב                |

## נגישות

ל־StatCard יש תפקיד סמנטי `group`, השם הנגיש לקוח מ־`label`, והתווית, הערך והדלתא נקראים ברצף על ידי טכנולוגיה מסייעת כטקסט בתוך הקבוצה. כאשר המגמה מובעת רק באמצעות צבע, ודאו שטקסט ה־`delta` עצמו נושא מידע כיווני (כמו קידומת `+`/`-`), ואל תסתמכו רק על צביעה באדום וירוק.
