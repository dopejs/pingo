# Typography

מערך טיפוגרפי: הכותרות `H1`–`H4`, פסקת `P`, וכן `Lead`, `Large`, `Small`, `Muted`,
`Blockquote` ו-`InlineCode`. את התצוגה המקדימה שלהלן מצייר מנוע pingo בזמן אמת, והיא עוקבת
אחרי מעבר הערכה הבהירה והכהה של האתר.

:::preview typography-scale
:::

## שימוש

```tsx
import { H1, Lead, P } from "@dopejs/pingo-ui";

root.render(
  <View style={{ flexDirection: "column" }}>
    <H1>מנוע רינדור</H1>
    <Lead>כותבים TSX על canvas, בלי לייצר DOM.</Lead>
    <P>פסקת טקסט.</P>
  </View>,
);
```

::: warning אלה אינם מכולות עוטפות
הטיפוגרפיה של shadcn מעצבת אלמנטי `h1`/`p` אמיתיים ונותנת למפל לשאת את גודל הגופן אל כל
תת-העץ. ב-pingo מדדי הטקסט **נפתרים לכל צומת בנפרד ואינם עוברים בירושה**: עטיפת טקסט
ב-`H1` לא תגדיל אותו. כל רכיב הוא צומת טקסט אחד, ו-`children` מקבל מחרוזת בלבד.
:::

## דוגמאות

### כותרות וגוף טקסט

‏`H1`–`H4` מקבילות לארבעת גדלי הכותרת של shadcn, ו-`P` היא פסקה של 16px/24px. התצוגה
המקדימה שלמעלה מציגה אותן לפי הסדר.

### ציטוט וקוד בתוך שורה

‏`Blockquote` הוא תיבה עם קו בצד, ו-`InlineCode` הוא מקטע עם רקע. שניהם בנויים משתי שכבות —
התיבה נושאת את המסגרת והריפוד, וצומת הטקסט נושא את הגודל והמשקל — מהסיבה שבאזהרה למעלה.

:::preview typography-blocks
:::

### להפריד בין הרמה המוכרזת לבין המדרגה החזותית

‏`H1` מדווח כרמה 1 כברירת מחדל. כשמבנה העמוד מחייב להתחיל ברמה 2 אך חזותית דרוש הגודל של
`H1`, אפשר לדרוס זאת עם `level`:

```tsx
<H1 level={2}>חזותית H1, ובמבנה רמה שנייה</H1>
```

## Props

### כותרות (`H1` / `H2` / `H3` / `H4`)

| Prop        | טיפוס                        | ברירת מחדל           | תיאור                    |
| ----------- | ---------------------------- | -------------------- | ------------------------ |
| `children`  | `string`                     | —                    | טקסט הכותרת (חובה)       |
| `level`     | `1 \| 2 \| 3 \| 4 \| 5 \| 6` | המדרגה של הרכיב עצמו | דורס את הרמה המדווחת     |
| `className` | `string`                     | —                    | מתווסף אחרי מחלקות הרכיב |

### היתר

‏`P`, `Lead`, `Large`, `Small`, `Muted`, `Blockquote` ו-`InlineCode` מקבלים רק
`children: string` ו-`className`.

| רכיב         | גודל / גובה שורה | שימוש                   |
| ------------ | ---------------- | ----------------------- |
| `P`          | 16 / 24          | פסקת גוף                |
| `Lead`       | 20 / 28          | פסקת פתיחה, בצבע מעומעם |
| `Large`      | 18 / 28          | טקסט מודגש במדרגה אחת   |
| `Small`      | 14 / 20          | טקסט משני               |
| `Muted`      | 14 / 20          | טקסט הסבר מעומעם        |
| `Blockquote` | 16 / 24          | ציטוט עם קו בצד         |
| `InlineCode` | 14 / 20          | קוד בתוך שורה, עם רקע   |

## נגישות

‏`H1`–`H4` נושאות סמנטיקת `heading` ומייצאות `aria-level`. **כותרת בלי רמה מוכרזת אצל רוב
קוראי המסך כרמה 2**, ולכן H1 ו-H4 היו נשמעות זהות: הרמה היא חלק מהרכיבים האלה, לא אפשרות.

היתר הם טקסט טהור ללא תפקיד: גוף הטקסט לא אמור לעצור קורא מסך בכל פסקה. אם דרושה להם
משמעות, הכניסו אותם למכולה שנושאת `semanticRole` במקום לתת תפקיד לפסקה עצמה.
