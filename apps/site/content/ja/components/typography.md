# Typography

タイポグラフィのコンポーネント一式です。見出し `H1`–`H4`、本文 `P`、そして `Lead`、
`Large`、`Small`、`Muted`、`Blockquote`、`InlineCode`。下のプレビューは pingo エンジンが
実時間で描画し、サイトのライト／ダーク切り替えに追随します。

:::preview typography-scale
:::

## 使い方

```tsx
import { H1, Lead, P } from "@dopejs/pingo-ui";

root.render(
  <View style={{ flexDirection: "column" }}>
    <H1>レンダリングエンジン</H1>
    <Lead>canvas に TSX を書き、DOM は作りません。</Lead>
    <P>本文の段落。</P>
  </View>,
);
```

::: warning これらはラッパーではありません
shadcn のタイポグラフィは実際の `h1`/`p` にスタイルを当て、カスケードで字サイズを部分木へ
伝えます。pingo のテキスト計量は**ノードごとに解決され、継承しません**。`H1` で文章を
囲んでも大きくなりません。各コンポーネントは 1 つのテキストノードで、`children` は文字列
だけを受け取ります。
:::

## 例

### 見出しと本文

`H1`–`H4` は shadcn の 4 段階の見出しサイズに対応し、`P` は 16px/24px の本文です。上の
プレビューが順に示します。

### 引用とインラインコード

`Blockquote` は左に罫線を持つボックス、`InlineCode` は背景を持つインライン片です。どちらも
「ボックスが枠線と内側の余白を、テキストノードがサイズと太さを持つ」二層構造です。理由は
上の注意書きのとおりです。

:::preview typography-blocks
:::

### 見出しレベルと視覚的な段を分ける

`H1` は既定でレベル 1 として報告されます。アウトライン上はレベル 2 で始めたいが見た目は
`H1` のサイズにしたい場合は `level` で上書きします。

```tsx
<H1 level={2}>見た目は H1、アウトラインは 2 級</H1>
```

## Props

### 見出し（`H1` / `H2` / `H3` / `H4`）

| Prop        | 型                           | 既定値                 | 説明                                 |
| ----------- | ---------------------------- | ---------------------- | ------------------------------------ |
| `children`  | `string`                     | —                      | 見出しの文字列（必須）               |
| `level`     | `1 \| 2 \| 3 \| 4 \| 5 \| 6` | コンポーネント自身の段 | 報告する見出しレベルを上書き         |
| `className` | `string`                     | —                      | コンポーネントのクラス名の後ろに追加 |

### その他

`P`、`Lead`、`Large`、`Small`、`Muted`、`Blockquote`、`InlineCode` は `children: string`
と `className` のみを受け取ります。

| コンポーネント | サイズ / 行高 | 用途                       |
| -------------- | ------------- | -------------------------- |
| `P`            | 16 / 24       | 本文の段落                 |
| `Lead`         | 20 / 28       | 導入段落、控えめな色       |
| `Large`        | 18 / 28       | 一段強調した本文           |
| `Small`        | 14 / 20       | 副次的なテキスト           |
| `Muted`        | 14 / 20       | 控えめな補足               |
| `Blockquote`   | 16 / 24       | 引用、左に罫線             |
| `InlineCode`   | 14 / 20       | インラインコード、背景つき |

## アクセシビリティ

`H1`–`H4` は `heading` のセマンティクスを持ち `aria-level` を出力します。**レベルのない
見出しは多くのスクリーンリーダーでレベル 2 と読み上げられる**ため、H1 と H4 が同じに
聞こえます。レベルはこの一式の一部であって、任意項目ではありません。

その他は役割を持たない純粋なテキストです。本文がスクリーンリーダーを段落ごとに止めるべき
ではないからです。意味を持たせたいときは、段落自体に役割を付けるのではなく
`semanticRole` を持つコンテナに入れてください。
