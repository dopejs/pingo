# Typography

타이포그래피 컴포넌트 모음입니다. 제목 `H1`–`H4`, 본문 `P`, 그리고 `Lead`, `Large`,
`Small`, `Muted`, `Blockquote`, `InlineCode`. 아래 미리보기는 pingo 엔진이 실시간으로
렌더링하며 사이트의 밝음/어두움 전환을 따릅니다.

:::preview typography-scale
:::

## 사용법

```tsx
import { H1, Lead, P } from "@dopejs/pingo-ui";

root.render(
  <View style={{ flexDirection: "column" }}>
    <H1>렌더링 엔진</H1>
    <Lead>canvas 에 TSX 를 쓰고 DOM 은 만들지 않습니다.</Lead>
    <P>본문 단락.</P>
  </View>,
);
```

::: warning 이들은 감싸는 컨테이너가 아닙니다
shadcn 의 타이포그래피는 실제 `h1`/`p` 에 스타일을 주고 캐스케이드로 글자 크기를 하위
트리에 전달합니다. pingo 의 텍스트 계측은 **노드마다 따로 계산되며 상속되지 않습니다**.
`H1` 로 문장을 감싼다고 커지지 않습니다. 각 컴포넌트는 하나의 텍스트 노드이고 `children`
은 문자열만 받습니다.
:::

## 예시

### 제목과 본문

`H1`–`H4` 는 shadcn 의 네 단계 제목 크기에 대응하고 `P` 는 16px/24px 본문입니다. 위
미리보기가 순서대로 보여 줍니다.

### 인용과 인라인 코드

`Blockquote` 는 왼쪽에 선이 있는 상자이고 `InlineCode` 는 배경이 있는 인라인 조각입니다.
둘 다 "상자가 테두리와 안쪽 여백을, 텍스트 노드가 크기와 굵기를 맡는" 두 층 구조입니다.
이유는 위 주의 사항과 같습니다.

:::preview typography-blocks
:::

### 제목 레벨과 시각적 단계를 분리하기

`H1` 은 기본적으로 레벨 1 로 보고됩니다. 개요상 레벨 2 로 시작해야 하지만 시각적으로는
`H1` 크기를 쓰고 싶다면 `level` 로 덮어씁니다.

```tsx
<H1 level={2}>보이기는 H1, 개요는 2단계</H1>
```

## Props

### 제목 (`H1` / `H2` / `H3` / `H4`)

| Prop        | 타입                         | 기본값             | 설명                        |
| ----------- | ---------------------------- | ------------------ | --------------------------- |
| `children`  | `string`                     | —                  | 제목 텍스트 (필수)          |
| `level`     | `1 \| 2 \| 3 \| 4 \| 5 \| 6` | 컴포넌트 자체 단계 | 보고할 제목 레벨을 덮어씀   |
| `className` | `string`                     | —                  | 컴포넌트 클래스명 뒤에 추가 |

### 나머지

`P`, `Lead`, `Large`, `Small`, `Muted`, `Blockquote`, `InlineCode` 는 `children: string`
과 `className` 만 받습니다.

| 컴포넌트     | 크기 / 행간 | 용도                   |
| ------------ | ----------- | ---------------------- |
| `P`          | 16 / 24     | 본문 단락              |
| `Lead`       | 20 / 28     | 도입 단락, 흐린 색     |
| `Large`      | 18 / 28     | 한 단계 강조한 본문    |
| `Small`      | 14 / 20     | 보조 텍스트            |
| `Muted`      | 14 / 20     | 흐린 설명 텍스트       |
| `Blockquote` | 16 / 24     | 인용, 왼쪽 선          |
| `InlineCode` | 14 / 20     | 인라인 코드, 배경 있음 |

## 접근성

`H1`–`H4` 는 `heading` 시맨틱을 가지고 `aria-level` 을 내보냅니다. **레벨이 없는 제목은
대부분의 스크린 리더에서 레벨 2 로 읽히기 때문에** H1 과 H4 가 같게 들립니다. 레벨은 이
모음의 일부이지 선택 사항이 아닙니다.

나머지는 역할이 없는 순수 텍스트입니다. 본문이 스크린 리더를 단락마다 멈추게 해서는 안
되기 때문입니다. 의미를 부여해야 한다면 단락 자체에 역할을 주지 말고 `semanticRole` 을
가진 컨테이너에 담으세요.
