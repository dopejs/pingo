# Alert Dialog

Диалог подтверждения — это Dialog со встроенной парой кнопок «Отмена / Подтвердить», предназначенный для повторного подтверждения перед необратимыми операциями. Превью ниже рендерится движком pingo в реальном времени и переключается между светлой и тёмной темой вслед за темой сайта.

:::preview alert-dialog-basic
:::

## Использование

```tsx
import { createElement } from "@dopejs/pingo";
import { AlertDialog } from "@dopejs/pingo-ui";

root.render(
  createElement(AlertDialog, {
    open,
    onOpenChange: (next) => setOpen(next),
    title: "确认退出？",
    description: "未保存的修改将会丢失。",
    onCancel: () => {},
    onAction: () => quit(),
    children: null,
  }),
);
```

Как и Dialog, оверлей заполняет собственный родительский контейнер, поэтому монтируйте его ближе к корневому узлу. Обратите внимание: `children` унаследован от `DialogProps` и остаётся обязательным, но переопределяется встроенной структурой заголовка/описания/кнопок — передавайте `null`. Нажатие кнопки отмены или подтверждения сначала вызывает соответствующий колбэк, а затем запрашивает закрытие через `onOpenChange(false)`; клик по подложке также закрывает диалог.

## Пропсы

Наследует `DialogProps` (`open`, `onOpenChange`, `children`, `className`), а также:

| Prop          | Тип          | По умолчанию | Описание                                             |
| ------------- | ------------ | ------------ | ---------------------------------------------------- |
| `title`       | `string`     | —            | Заголовок (обязателен)                               |
| `description` | `string`     | —            | Дополнительное пояснение                             |
| `cancelLabel` | `string`     | `"取消"`     | Текст кнопки отмены                                  |
| `actionLabel` | `string`     | `"确定"`     | Текст кнопки подтверждения                           |
| `onCancel`    | `() => void` | —            | Колбэк отмены (после него диалог закрывается)        |
| `onAction`    | `() => void` | —            | Колбэк подтверждения (после него диалог закрывается) |
| `destructive` | `boolean`    | `false`      | Кнопка подтверждения в цвете опасности               |

## Доступность

Имеет семантику dialog; кнопки отмены и подтверждения включены в Tab-цикл, поэтому пользователи клавиатуры не застрянут внутри диалога.
