# Alert

Alert показывает на странице подсказки, которые требуют внимания пользователя, но не прерывают его работу. Превью ниже рендерится движком pingo в реальном времени и переключается между светлой и тёмной темой вслед за темой сайта.

:::preview alert-basic
:::

## Использование

```tsx
import { Alert } from "@dopejs/pingo-ui";

root.render(<Alert title="提示">你的配置已自动保存。</Alert>);
```

## Примеры

### Деструктивная подсказка

`variant="destructive"` применяется в сценариях ошибок и сбоев: рамка и заголовок получают деструктивные цвета, а текст описания остаётся обычного цвета переднего плана ради читаемости.

```tsx
<Alert title="同步失败" variant="destructive">
  请检查网络连接后重试。
</Alert>
```

## Пропсы

| Prop        | Тип                          | По умолчанию | Описание                                  |
| ----------- | ---------------------------- | ------------ | ----------------------------------------- |
| `title`     | `string`                     | —            | Заголовок (обязателен)                    |
| `children`  | `string`                     | —            | Текст описания (обязателен)               |
| `variant`   | `"default" \| "destructive"` | `"default"`  | Визуальный вариант                        |
| `className` | `string`                     | —            | Добавляется после имени класса компонента |

## Доступность

Alert — чисто статический текстовый блок, он не перехватывает фокус; формулируйте вывод кратко в `title`, а детали помещайте в описание. Для сценариев, требующих подтверждения или обработки пользователем, используйте `AlertDialog`.
