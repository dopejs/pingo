# Aspect Ratio

Aspect Ratio сохраняет для контента фиксированное соотношение сторон: ширину определяет раскладка, а высота вычисляется автоматически по этому соотношению. Превью ниже рендерится движком pingo в реальном времени.

:::preview aspect-ratio-basic
:::

## Использование

```tsx
import { AspectRatio } from "@dopejs/pingo-ui";

root.render(<AspectRatio ratio={16 / 9}>{coverImage}</AspectRatio>);
```

Ширина компонента составляет 100% родительского контейнера; `ratio` — это ширина, делённая на высоту, например `16 / 9` означает широкоэкранный формат.

## Пропсы

| Prop        | Тип         | По умолчанию | Описание                                  |
| ----------- | ----------- | ------------ | ----------------------------------------- |
| `ratio`     | `number`    | `1`          | Соотношение сторон (ширина ÷ высота)      |
| `children`  | `PingoNode` | —            | Ограничиваемое содержимое (обязательно)   |
| `className` | `string`    | —            | Добавляется после имени класса компонента |

## Доступность

Aspect Ratio — чисто раскладочный контейнер, он не вводит дополнительной семантики. Поскольку в подмножестве CSS нет свойства `aspect-ratio`, компонент вычисляет высоту по фактически измеренной ширине: первый кадр рендерится с нулевой высотой, а окончательная высота определяется после прибытия измерения.
