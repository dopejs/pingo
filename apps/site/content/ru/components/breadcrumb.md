# Breadcrumb

Хлебные крошки: каждый пункт, кроме последнего, — кликабельная ссылка; последний пункт обозначает текущую страницу — он не рендерится ссылкой и не предоставляет вспомогательным технологиям действия «перейти к текущему месту». Превью ниже рендерится движком pingo в реальном времени — предыдущие пункты можно щёлкать и активировать с клавиатуры, превью переключается между светлой и тёмной темой вслед за темой сайта.

:::

## Использование

```tsx
import { createElement } from "@dopejs/pingo";
import { Breadcrumb } from "@dopejs/pingo-ui";

root.render(
  createElement(Breadcrumb, {
    items: [
      { label: "首页", onNavigate: () => navigate("/") },
      { label: "组件", onNavigate: () => navigate("/components") },
      { label: "Breadcrumb" }, // 末项是当前页，无需 onNavigate
    ],
  }),
);
```

## Пропсы

### BreadcrumbProps

| Prop        | Тип                         | По умолчанию | Описание                                                                  |
| ----------- | --------------------------- | ------------ | ------------------------------------------------------------------------- |
| `items`     | `readonly BreadcrumbItem[]` | —            | Пункты хлебных крошек; последний считается текущей страницей (обязателен) |
| `separator` | `string`                    | `"/"`        | Разделитель между пунктами                                                |
| `className` | `string`                    | —            | Добавляется после имени класса компонента                                 |

### BreadcrumbItem

| Поле         | Тип          | По умолчанию | Описание                                                                                                                                         |
| ------------ | ------------ | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `label`      | `string`     | —            | Текст пункта (обязателен)                                                                                                                        |
| `onNavigate` | `() => void` | —            | Колбэк щелчка; если не задан, пункт не несёт никакого поведения активации (последний пункт и так считается текущей страницей, задавать не нужно) |

## Доступность

Хлебные крошки целиком несут семантику `navigation` с именем "breadcrumb"; кликабельные пункты имеют семантику link, поддерживают активацию клавишами `Enter` / `Space` и получают фокус перед щелчком. Текущая страница рендерится обычным текстом со значением семантики `current`, и скринридер не воспринимает её как ссылку для перехода. Подробнее — в [руководстве по доступности](/guide/accessibility).
