# Button

Кнопка запускает действие. Превью ниже рендерится движком pingo в реальном времени — её можно нажимать и фокусировать, она переключается между светлой и тёмной темой вслед за темой сайта.

:::preview button-basic
:::

## Использование

```tsx
import { Button } from "@dopejs/pingo-ui";

root.render(
  <Button variant="default" onPress={() => save()}>
    保存
  </Button>,
);
```

## Примеры

### Размеры

`size` поддерживает `default`, `sm`, `lg` и `icon`.

### Отключённое состояние

С переданным `disabled` кнопка перестаёт реагировать на указатель и клавиатуру и получает стили отключённого состояния.

## Пропсы

| Prop            | Тип                                                                 | По умолчанию | Описание                                  |
| --------------- | ------------------------------------------------------------------- | ------------ | ----------------------------------------- |
| `children`      | `string`                                                            | —            | Текст кнопки (обязателен)                 |
| `variant`       | `"default" \| "secondary" \| "outline" \| "ghost" \| "destructive"` | `"default"`  | Визуальный вариант                        |
| `size`          | `"default" \| "sm" \| "lg" \| "icon"`                               | `"default"`  | Размер                                    |
| `disabled`      | `boolean`                                                           | `false`      | Отключённое состояние                     |
| `onPress`       | `() => void`                                                        | —            | Колбэк активации указателем/клавиатурой   |
| `semanticLabel` | `string`                                                            | `children`   | Доступное имя                             |
| `className`     | `string`                                                            | —            | Добавляется после имени класса компонента |

## Доступность

Кнопка несёт семантику button и поддерживает активацию с клавиатуры; `semanticLabel` по умолчанию берётся из `children` — для кнопок-иконок указывайте его явно.
