# Checkbox

Флажок служит для независимых булевых переключателей. Превью ниже рендерится движком pingo в реальном времени и переключается между светлой и тёмной темой вслед за темой сайта. Checkbox — контролируемый компонент: в превью показана статическая комбинация вкл/выкл/отключён, а интерактивность задаётся состоянием на стороне вызывающего кода.

## Использование

```tsx
import { createElement, useSignal, type PingoNode } from "@dopejs/pingo";
import { Checkbox } from "@dopejs/pingo-ui";

// useSignal 是 hook，必须运行在组件作用域内。
function NotificationSetting(): PingoNode {
  const enabled = useSignal(false);
  return createElement(Checkbox, {
    checked: enabled.get(),
    label: "已启用通知",
    onCheckedChange: (next) => enabled.set(next),
  });
}

root.render(createElement(NotificationSetting));
```

`checked` хранится в родительском компоненте, а `onCheckedChange` обновляет его — сам компонент состояния не хранит. `label` необязателен: если задан, текст рендерится справа от флажка.

## Примеры

### Отключённое состояние

С переданным `disabled` флажок перестаёт реагировать на указатель и клавиатуру, а семантическое значение становится `disabled`.

## Пропсы

| Prop              | Тип                          | По умолчанию | Описание                                       |
| ----------------- | ---------------------------- | ------------ | ---------------------------------------------- |
| `checked`         | `boolean`                    | —            | Состояние отметки (обязателен, контролируемый) |
| `onCheckedChange` | `(checked: boolean) => void` | —            | Колбэк переключения состояния                  |
| `disabled`        | `boolean`                    | `false`      | Отключённое состояние                          |
| `label`           | `string`                     | —            | Текстовая метка справа от флажка               |
| `className`       | `string`                     | —            | Добавляется после имени класса компонента      |
| `semanticLabel`   | `string`                     | —            | Доступное имя                                  |

## Доступность

Компонент несёт семантическую роль `checkbox`, его семантическое значение переключается между `checked` / `unchecked` / `disabled`. При нажатии указателем фокус устанавливается автоматически. Индикатор ✓ зависит от покрытия глифов шрифтом и до готовности иконочных ассетов служит заглушкой.
