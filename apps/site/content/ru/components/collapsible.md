# Collapsible

Collapsible — одноэлементный примитив Accordion: один триггер управляет разворачиванием и сворачиванием блока контента; подходит, когда нужна всего одна складная область. Превью ниже рендерится движком pingo в реальном времени — щёлкайте по триггеру для переключения.

:::preview collapsible-basic
:::

## Использование

```tsx
import { Collapsible } from "@dopejs/pingo-ui";

root.render(
  <Collapsible trigger="高级选项" defaultOpen>
    <text value="折叠区内容。" />
  </Collapsible>,
);
```

Поддерживаются оба режима: неконтролируемый (`defaultOpen`) и контролируемый (`open` + `onOpenChange`).

## Примеры

### Отключённое состояние

С переданным `disabled` триггер перестаёт реагировать на указатель и клавиатуру и получает стили отключённого состояния.

## Пропсы

| Prop           | Тип                       | По умолчанию | Описание                                                    |
| -------------- | ------------------------- | ------------ | ----------------------------------------------------------- |
| `trigger`      | `string`                  | —            | Текст триггера (обязателен)                                 |
| `children`     | `PingoNode`               | —            | Содержимое, отображаемое после разворачивания (обязательно) |
| `open`         | `boolean`                 | —            | Контролируемый режим: текущее состояние развёрнутости       |
| `defaultOpen`  | `boolean`                 | `false`      | Неконтролируемый режим: изначальное состояние развёрнутости |
| `onOpenChange` | `(open: boolean) => void` | —            | Колбэк смены состояния развёрнутости                        |
| `disabled`     | `boolean`                 | `false`      | Отключает триггер                                           |
| `className`    | `string`                  | —            | Добавляется после имени класса компонента                   |

## Доступность

Триггер несёт семантику button и сообщает вспомогательным технологиям состояние expanded/collapsed; Enter и Пробел переключают разворачивание. При сворачивании содержимое скрывается через `display: none`, а не выгружается, поэтому позиция прокрутки и состояние редактирования внутри сохраняются.
