# Command

Command — командная палитра со строкой поиска: ввод мгновенно фильтрует пункты, клавиши-стрелки двигают курсор, Enter подтверждает. Превью ниже рендерится движком pingo в реальном времени — просто начните вводить в строке поиска для фильтрации; превью переключается между светлой и тёмной темой вслед за темой сайта.

:::

## Использование

```tsx
import { Command } from "@dopejs/pingo-ui";

root.render(
  <Command
    items={[
      { value: "open", label: "打开文件" },
      { value: "save", label: "保存文件" },
    ]}
    onSelect={(value) => run(value)}
    onDismiss={() => closePalette()}
  />,
);
```

Фильтрация — регистронезависимое совпадение подстроки в метке; нечёткий поиск не применяется намеренно: стратегия ранжирования — продуктовое решение, и компонент не подменяет вызывающий код. `onDismiss` срабатывает по `Escape`, если не совпала клавиша навигации, — удобно обернуть палитру в Dialog для сценария «⌘K».

## Пропсы

| Prop          | Тип                       | По умолчанию | Описание                                |
| ------------- | ------------------------- | ------------ | --------------------------------------- |
| `items`       | `readonly CommandItem[]`  | —            | Пункты команд (обязателен)              |
| `onSelect`    | `(value: string) => void` | —            | Колбэк выбора пункта (щелчок или Enter) |
| `onDismiss`   | `() => void`              | —            | Колбэк `Escape`                         |
| `placeholder` | `string`                  | `"搜索"`     | Доступное имя строки поиска             |
| `emptyLabel`  | `string`                  | `"无结果"`   | Текст при пустом результате фильтрации  |
| `className`   | `string`                  | —            | Добавочное имя класса                   |

### CommandItem

| Поле    | Тип      | Описание                                       |
| ------- | -------- | ---------------------------------------------- |
| `value` | `string` | Значение пункта (обязателен)                   |
| `label` | `string` | Текст отображения и сопоставления (обязателен) |

## Доступность

Контейнер несёт семантику search, пункты — семантику option с выставляемым состоянием selected; стрелки вверх/вниз двигают курсор, `Enter` подтверждает, `Escape` вызывает `onDismiss`.
