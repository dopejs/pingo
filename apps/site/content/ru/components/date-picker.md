# Date Picker

Выбор даты — это [Calendar](/components/calendar), привязанный к значению: триггер плюс всплывающий месячный календарь. Превью ниже рендерится движком pingo в реальном времени — календарь развёрнут: можно листать месяцы и щёлкать по датам; превью переключается между светлой и тёмной темой вслед за темой сайта.

:::preview date-picker-basic
:::

## Использование

```tsx
import { DatePicker, type CalendarDate } from "@dopejs/pingo-ui";

root.render(
  <DatePicker placeholder="选择日期" onSelect={(date: CalendarDate) => console.log(date)} />,
);
```

Дата представлена как `CalendarDate` (`{ year, month, day }`) — поля хранятся раздельно, и никакой часовой пояс не сможет сдвинуть её на день. После выбора даты всплывающий слой сворачивается автоматически: выбор, остающийся открытым, был бы просто календарём.

## Примеры

### Форматирование и заполнитель

Триггер по умолчанию показывает выбранную дату в формате `YYYY-MM-DD`; `format` задаёт собственный рендеринг, `placeholder` — текст-заполнитель, пока ничего не выбрано.

### Контролируемое открытие

`open` и `onOpenChange` образуют контролируемое открытие; если их не задать, компонент хранит состояние открытия сам.

## Пропсы

| Prop            | Тип                               | По умолчанию                           | Описание                                                    |
| --------------- | --------------------------------- | -------------------------------------- | ----------------------------------------------------------- |
| `value`         | `CalendarDate`                    | —                                      | Выбранная дата                                              |
| `month`         | `CalendarDate`                    | —                                      | Контролируемый отображаемый месяц                           |
| `defaultMonth`  | `CalendarDate`                    | `value ?? 2026-01-01`                  | Неконтролируемый начальный месяц                            |
| `onSelect`      | `(date: CalendarDate) => void`    | —                                      | Колбэк выбора даты (затем слой сворачивается автоматически) |
| `onMonthChange` | `(month: CalendarDate) => void`   | —                                      | Колбэк перелистывания                                       |
| `weekdayLabels` | `readonly string[]`               | `["日","一","二","三","四","五","六"]` | Заголовки дней недели                                       |
| `monthLabel`    | `(month: CalendarDate) => string` | —                                      | Собственный заголовок месяца                                |
| `isDisabled`    | `(date: CalendarDate) => boolean` | —                                      | Отключение отдельных дат                                    |
| `open`          | `boolean`                         | —                                      | Контролируемое открытие                                     |
| `onOpenChange`  | `(open: boolean) => void`         | —                                      | Колбэк открытия/закрытия                                    |
| `placeholder`   | `string`                          | `"选择日期"`                           | Текст-заполнитель, пока ничего не выбрано                   |
| `format`        | `(date: CalendarDate) => string`  | `formatDate`（`YYYY-MM-DD`）           | Рендеринг даты на триггере                                  |
| `className`     | `string`                          | —                                      | Добавляется после имени класса компонента                   |

## Доступность

Триггер несёт семантику button и переключается между `expanded` / `collapsed`; календарная часть наследует сеточную семантику Calendar. При открытии слоя фокус переходит в панель, при сворачивании — возвращается к триггеру.
