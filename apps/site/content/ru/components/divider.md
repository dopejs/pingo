# Divider

Разделительная линия обеспечивает визуальную группировку содержимого. Превью ниже отрисовывается движком pingo в реальном времени и переключается между светлой и тёмной темой вместе с сайтом.

:::preview divider-horizontal
:::

## Использование

```tsx
import { createElement } from "@dopejs/pingo";
import { Divider } from "@dopejs/pingo-ui";

root.render(createElement(Divider, {}));
```

## Примеры

### Вертикальная разделительная линия

Передайте `orientation: "vertical"`, чтобы получить вертикальную разделительную линию. Её высота составляет 100% высоты родительского контейнера, поэтому родительский контейнер должен иметь определённую высоту.

:::preview divider-vertical
:::

## Props

| Prop          | Тип                          | Значение по умолчанию | Описание                              |
| ------------- | ---------------------------- | --------------------- | ------------------------------------- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"`        | Направление разделительной линии      |
| `className`   | `string`                     | —                     | Добавляется к имени класса компонента |

Горизонтальная линия имеет ширину 100% родительского контейнера и высоту 1px; вертикальная — высоту 100% родительского контейнера и ширину 1px.

## Доступность

Divider — чисто визуальный элемент без семантической роли, вспомогательные технологии его игнорируют; группировку содержимого следует выражать семантическими структурами, например заголовками.
