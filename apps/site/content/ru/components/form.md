# Form

`Form` — контейнер формы, а `FormField` собирает метку, элемент управления и сообщения об ошибке/описание в одно поле. Превью ниже отрисовывается движком pingo в реальном времени — поля ввода внутри можно по-настоящему редактировать; превью переключается между светлой и тёмной темой вместе с сайтом.

:::

## Использование

```tsx
import { createElement } from "@dopejs/pingo";
import { Form, FormField, Input } from "@dopejs/pingo-ui";

root.render(
  createElement(Form, {
    children: createElement(FormField, {
      label: "邮箱",
      required: true,
      error: emailError, // 校验规则由调用方持有
      children: createElement(Input, {
        semanticLabel: "邮箱",
        onValueChange: (value) => validate(value),
      }),
    }),
  }),
);
```

Валидации внутри компонента нет: когда валидировать, какую ошибку показывать и как комбинировать правила — это продуктовое решение. Вызывающая сторона хранит правила и передаёт `error`; компонент отвечает только за раскладку, семантику и места под сообщения.

## Примеры

### Ошибка и описание

При наличии `error` поле помечается недействительным, и текст ошибки **заменяет** описание — если в двух строках подсказки одна содержит сообщение о неудаче, другая её заглушит. `required` добавляет к метке маркер `*`.

## Props

### Form

| Prop        | Тип         | Значение по умолчанию | Описание                              |
| ----------- | ----------- | --------------------- | ------------------------------------- |
| `children`  | `PingoNode` | —                     | Содержимое формы (обязательно)        |
| `className` | `string`    | —                     | Добавляется к имени класса компонента |

### FormField

| Prop          | Тип         | Значение по умолчанию | Описание                                                                            |
| ------------- | ----------- | --------------------- | ----------------------------------------------------------------------------------- |
| `label`       | `string`    | —                     | Метка поля (обязательно)                                                            |
| `children`    | `PingoNode` | —                     | Элемент управления поля (обязательно)                                               |
| `error`       | `string`    | —                     | Сообщение об ошибке; при наличии помечает поле недействительным и заменяет описание |
| `description` | `string`    | —                     | Вспомогательный текст описания                                                      |
| `required`    | `boolean`   | `false`               | Маркер обязательности, добавляет `*` к метке                                        |
| `className`   | `string`    | —                     | Добавляется к имени класса компонента                                               |

## Доступность

`Form` имеет семантическую роль `form`; `FormField` имеет семантику `group` и называется меткой, а при недействительности его семантическое значение — `invalid`. Семантика размещается на группе, а не на элементе управления — элемент управления принадлежит вызывающей стороне, группа — единственный элемент, который гарантированно существует.
