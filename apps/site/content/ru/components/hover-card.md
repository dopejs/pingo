# Hover Card

Hover Card разворачивает карточку с богатым содержимым при наведении (или фокусе) на триггер — она вмещает больше информации, чем Tooltip, например превью профиля пользователя. Превью ниже рендерится движком pingo в реальном времени (показано с контролируемым `open`, постоянно открытым) и переключается между светлой и тёмной темой вслед за темой сайта.

## Использование

```tsx
import { HoverCard } from "@dopejs/pingo-ui";

root.render(
  <HoverCard
    openDelayMs={300}
    closeDelayMs={200}
    content={<text value="Canvas 渲染引擎与 UI 组件库。" />}
  >
    <text value="@pingo" />
  </HoverCard>,
);
```

После открытия карточка не закрывается и при наведении на саму карточку, поэтому `closeDelayMs` даёт указателю время преодолеть зазор между триггером и карточкой. Передача `open` переводит компонент в контролируемый режим — управляйте состоянием сами в связке с `onOpenChange`.

## Пропсы

| Prop           | Тип                       | По умолчанию | Описание                                           |
| -------------- | ------------------------- | ------------ | -------------------------------------------------- |
| `children`     | `PingoNode`               | —            | Элемент-триггер (обязателен)                       |
| `content`      | `PingoNode`               | —            | Содержимое карточки (обязательно)                  |
| `open`         | `boolean`                 | —            | Контролируемое состояние открытия                  |
| `onOpenChange` | `(open: boolean) => void` | —            | Колбэк открытия/закрытия                           |
| `openDelayMs`  | `number`                  | `300`        | Задержка открытия (мс)                             |
| `closeDelayMs` | `number`                  | `200`        | Задержка закрытия (мс)                             |
| `className`    | `string`                  | —            | Добавляется после имени класса якорного контейнера |

## Доступность

Триггер открывает карточку и при получении фокуса, а при потере фокуса закрывает — пользователи клавиатуры не теряют содержимое.
