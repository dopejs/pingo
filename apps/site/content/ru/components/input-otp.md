# Input OTP

Поле ввода одноразового кода, состоящее из нескольких ячеек фиксированной длины. Превью ниже рендерится движком pingo в реальном времени — цифры можно вводить по ячейкам или вставлять весь код целиком; превью переключается между светлой и тёмной темой вслед за темой сайта.

:::

## Использование

```tsx
import { createElement } from "@dopejs/pingo";
import { InputOTP } from "@dopejs/pingo-ui";

root.render(
  createElement(InputOTP, {
    length: 6,
    semanticLabel: "一次性验证码",
    onValueChange: (value) => console.log(value),
    onComplete: (code) => verify(code),
  }),
);
```

Внутреннее значение — строка **фиксированной длины, дополненная пробелами**: пробел означает пустую ячейку. `onValueChange` получает именно эту дополненную строку; `onComplete` срабатывает один раз, когда все ячейки заполнены, и получает полный код без пробелов. Вставка трактуется как заполнение целого фрагмента начиная с текущей ячейки, а удаление очищает только текущую ячейку, не сдвигая последующие цифры влево.

## Примеры

### Длина

`length` задаёт число ячеек (по умолчанию 6). Каждая ячейка использует цифровую экранную клавиатуру (`inputMode: "numeric"`).

## Пропсы

| Prop            | Тип                       | По умолчанию | Описание                                                                                |
| --------------- | ------------------------- | ------------ | --------------------------------------------------------------------------------------- |
| `length`        | `number`                  | `6`          | Число ячеек                                                                             |
| `value`         | `string`                  | —            | Контролируемое текущее значение (дополнено пробелами)                                   |
| `defaultValue`  | `string`                  | —            | Неконтролируемое начальное значение                                                     |
| `onValueChange` | `(value: string) => void` | —            | Колбэк изменения значения; значение — строка фиксированной длины, дополненная пробелами |
| `onComplete`    | `(value: string) => void` | —            | Колбэк при заполнении всех ячеек; значение — полный код без пробелов                    |
| `disabled`      | `boolean`                 | `false`      | Отключает все ячейки                                                                    |
| `semanticLabel` | `string`                  | —            | Доступное имя группы                                                                    |
| `className`     | `string`                  | —            | Добавляется после имени класса компонента                                               |

## Доступность

Компонент несёт семантическую роль `group`; каждая ячейка автоматически получает доступное имя вида `номер/всего` (например, `3/6`), а всю группу можно назвать через `semanticLabel`.
