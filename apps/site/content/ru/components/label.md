# Label

Метка задаёт видимое имя элемента формы. Превью ниже рендерится движком pingo в реальном времени и переключается между светлой и тёмной темой вместе с сайтом.

:::preview label-basic
:::

## Использование

```tsx
import { Input, Label } from "@dopejs/pingo-ui";

root.render(
  <container style={{ flexDirection: "column" }}>
    <Label>邮箱</Label>
    <container height={8} />
    <Input semanticLabel="邮箱" width={320} />
  </container>,
);
```

В pingo нет свойства `gap`, поэтому отступ между меткой и элементом управления делается контейнером фиксированного размера.

## Примеры

### Семантическое имя

Связывания метки с элементом управления в pingo пока нет, поэтому связь держится на соглашении: передайте элементу управления `semanticLabel`, совпадающий с текстом метки, чтобы скринридер озвучил то же имя.

## Props

| Prop            | Тип      | По умолчанию | Описание                                                                          |
| --------------- | -------- | ------------ | --------------------------------------------------------------------------------- |
| `children`      | `string` | —            | Текст метки (обязательно)                                                         |
| `className`     | `string` | —            | Добавляется после класса компонента                                               |
| `semanticLabel` | `string` | —            | Переопределяет имя для средств доступности; по умолчанию используется текст метки |

## Доступность

В pingo пока нет механизма связи label–control, Label — это просто стилизованный текст. Всегда задавайте `semanticLabel` на соответствующем элементе управления, чтобы имя для средств доступности не зависело от визуальной близости.
