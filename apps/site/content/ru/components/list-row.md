# ListRow

ListRow — специфичная для pingo продуктовая молекула: строка списка, где заголовок и описание занимают растягивающуюся центральную колонку, а слоты `leading` (аватар, иконка) и `trailing` (значок, переключатель, стрелка) расположены по краям. Превью ниже рендерится движком pingo в реальном времени — у кликабельных строк есть полная реакция на указатель, а тема переключается между светлой и тёмной вместе с сайтом.

:::preview list-row-basic
:::

Связь с базовыми элементами shadcn: ListRow задаёт раскладку строки и состояния взаимодействия и не содержит встроенных компонентов контента; слоты `leading`/`trailing` принимают любой `PingoNode`, типичная комбинация — Avatar, Badge или Switch. Когда между соседними строками нужен отступ, используйте container фиксированной высоты (в pingo нет свойства gap).

## Использование

```tsx
import { createElement } from "@dopejs/pingo";
import { Avatar, Badge, ListRow } from "@dopejs/pingo-ui";

root.render(
  createElement(ListRow, {
    title: "张三",
    description: "zhangsan@example.com",
    leading: createElement(Avatar, { fallback: "张", size: 32 }),
    trailing: createElement(Badge, { children: "管理员" }),
    onPress: () => openMember("zhangsan"),
  }),
);
```

## Примеры

### Выбор и отключение

`selected` применяет стиль выбранного состояния и экспонирует его наружу; отключённая строка не несёт никаких обработчиков событий — это строже, чем «проверить внутри обработчика».

:::preview list-row-states
:::

### Чисто презентационная строка

Без `onPress` строка ведёт себя как чисто презентационный элемент: семантическая роль `listitem`, без интерактивных стилей и событий.

## Props

| Prop          | Тип          | По умолчанию | Описание                                                                                    |
| ------------- | ------------ | ------------ | ------------------------------------------------------------------------------------------- |
| `title`       | `string`     | —            | Текст заголовка (обязательно)                                                               |
| `description` | `string`     | —            | Вторичный текст описания                                                                    |
| `leading`     | `PingoNode`  | —            | Передний слот, для аватара или иконки                                                       |
| `trailing`    | `PingoNode`  | —            | Задний слот, для значка, переключателя или стрелки                                          |
| `selected`    | `boolean`    | —            | Состояние выбора; при передаче экспонируются семантические значения `selected`/`unselected` |
| `disabled`    | `boolean`    | `false`      | Отключённое состояние, обработчики событий не регистрируются                                |
| `onPress`     | `() => void` | —            | Колбэк нажатия; при передаче строка становится интерактивной                                |
| `className`   | `string`     | —            | Добавляется после класса компонента                                                         |

## Доступность

Интерактивная строка имеет семантическую роль `button`, чисто презентационная — `listitem`; имя для средств доступности берётся из `title`. При передаче `selected` экспонируются семантические значения `selected`/`unselected`. Отключённая строка не несёт никаких обработчиков указателя и клавиатуры и представляется вспомогательным технологиям как чисто статический элемент.
