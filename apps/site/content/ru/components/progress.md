# Progress

Progress показывает детерминированный прогресс заполненной дорожкой — например, загрузку, выгрузку или многошаговую задачу. Превью ниже рендерится движком pingo в реальном времени и переключается между светлой и тёмной темой вслед за темой сайта.

:::preview progress-basic
:::

## Использование

```tsx
import { Progress } from "@dopejs/pingo-ui";

root.render(<Progress value={60} />);
```

Ширина дорожки наследуется от родительского контейнера; чтобы управлять длиной полосы, поместите Progress в контейнер с фиксированной шириной:

```tsx
<container width={320}>
  <Progress value={60} />
</container>
```

## Примеры

### Собственный максимум

`max` по умолчанию равен 100. Если его передать, процент заполнения вычисляется как `value / max` и всегда ограничивается диапазоном 0–100:

```tsx
<Progress value={3} max={10} /> // 30%
```

## Пропсы

| Prop        | Тип      | По умолчанию | Описание                                                             |
| ----------- | -------- | ------------ | -------------------------------------------------------------------- |
| `value`     | `number` | —            | Текущий прогресс (обязателен); значения вне диапазона ограничиваются |
| `max`       | `number` | `100`        | Максимальное значение, обрабатывается как минимум 1                  |
| `className` | `string` | —            | Добавляется после имени класса компонента                            |

## Доступность

Progress — чисто визуальный элемент без семантической роли. Если прогресс критичен для завершения задачи, сопровождайте его текстом с текущим процентом или названием этапа.
