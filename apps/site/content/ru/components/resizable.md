# Resizable

Resizable делит контейнер на две панели, а перетаскиваемая ручка между ними изменяет пропорцию; поддерживается и точная настройка с клавиатуры. Превью ниже рендерится движком pingo в реальном времени — попробуйте перетащить ручку.

:::preview resizable-basic
:::

## Использование

```tsx
import { createElement } from "@dopejs/pingo";
import { Resizable } from "@dopejs/pingo-ui";

root.render(
  createElement(Resizable, {
    defaultSplit: 0.4,
    first: sidebar,
    second: content,
  }),
);
```

Ширина и высота компонента составляют 100% родительского контейнера — нужен родитель с определёнными размерами. Поддерживаются оба режима: неконтролируемый (`defaultSplit`) и контролируемый (`split` + `onSplitChange`).

## Примеры

### Вертикальное направление

Передайте `direction: "column"`, чтобы переключиться на разбиение сверху вниз — ручка станет горизонтальной.

## Пропсы

| Prop            | Тип                       | По умолчанию | Описание                                           |
| --------------- | ------------------------- | ------------ | -------------------------------------------------- |
| `first`         | `PingoNode`               | —            | Содержимое первой панели (обязательно)             |
| `second`        | `PingoNode`               | —            | Содержимое второй панели (обязательно)             |
| `split`         | `number`                  | —            | Контролируемый режим: доля первой панели, `[0, 1]` |
| `defaultSplit`  | `number`                  | `0.5`        | Неконтролируемый режим: начальная доля             |
| `onSplitChange` | `(split: number) => void` | —            | Колбэк изменения доли                              |
| `direction`     | `"row" \| "column"`       | `"row"`      | Направление разбиения                              |
| `minSplit`      | `number`                  | `0.1`        | Минимальная доля (нижняя граница ограничения)      |
| `maxSplit`      | `number`                  | `0.9`        | Максимальная доля (верхняя граница ограничения)    |
| `disabled`      | `boolean`                 | `false`      | Отключает взаимодействие с ручкой                  |
| `className`     | `string`                  | —            | Добавляется после имени класса компонента          |

## Доступность

Ручка несёт семантику separator и сообщает вспомогательным технологиям текущую долю (в процентах). После фокусировки ручки клавиши-стрелки настраивают долю с шагом 2%: в горизонтальной раскладке — влево/вправо, в вертикальной — вверх/вниз.
