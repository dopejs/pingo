# Sheet

Sheet выдвигает панель от края контейнера и обычно используется для вторичного содержимого, не прерывающего основной поток, — условий фильтрации, боковых панелей с деталями и т. п. Превью ниже рендерится движком pingo в реальном времени и переключает светлую и тёмную тему вместе с темой сайта.

:::

## Использование

```tsx
import { createElement } from "@dopejs/pingo";
import { Sheet } from "@dopejs/pingo-ui";

root.render(
  createElement(Sheet, {
    open,
    onOpenChange: (next) => setOpen(next),
    side: "right",
    children: createElement("text", { value: "面板内容" }),
  }),
);
```

Оверлей заполняет собственный родительский контейнер, поэтому монтируйте его ближе к корню. `open` — контролируемый проп; клик по подложке или нажатие `Escape` запрашивает закрытие через `onOpenChange(false)`. Для блоков заголовка и кнопок внутри панели можно переиспользовать `DialogHeader`, `DialogTitle`, `DialogDescription` и `DialogFooter`.

## Примеры

### Направление

`side` принимает `"left"`, `"right"`, `"top"`, `"bottom"`, по умолчанию `"right"`. Когда нужны только верхний и нижний края, используйте семантически более точный [Drawer](/components/drawer).

## Props

Наследует `DialogProps` (`open`, `onOpenChange`, `children`, `className`), а также:

| Prop   | Тип                                      | По умолчанию | Описание                     |
| ------ | ---------------------------------------- | ------------ | ---------------------------- |
| `side` | `"left" \| "right" \| "top" \| "bottom"` | `"right"`    | Край, откуда выезжает панель |

## Доступность

Панель имеет семантику complementary; при открытии фокус перемещается внутрь панели, а после закрытия по `Escape` возвращается на исходный элемент.
