# StatCard

StatCard — продуктовая молекула, специфичная для pingo: плитка метрики из метки, значения, дельты к прошлому периоду и поясняющего текста. `trend` влияет только на окраску дельты — `flat` остаётся нейтрально-серым, ведь у неизменной метрики нет «хорошего» или «плохого» направления. Превью ниже рендерится движком pingo в реальном времени и переключается между светлой и тёмной темой вслед за темой сайта.

:::preview statcard-basic
:::

Связь с базовыми компонентами shadcn: StatCard — самодостаточная презентационная молекула, внутри используются только примитивы Text/View, слоты не предусмотрены; на дашбордах несколько StatCard обычно выстраивают в ряд контейнером с `flexDirection: "row"` или комбинируют с Card и Divider в отчётные блоки. Форматирование значений (разряды, символ валюты) выполняет вызывающий код — `value`/`delta` являются обычными строками.

## Использование

```tsx
import { StatCard } from "@dopejs/pingo-ui";

root.render(
  <StatCard label="本月营收" value="¥128,400" delta="+12.5%" trend="up" description="较上月" />,
);
```

## Примеры

### Трендовая окраска

`trend` принимает `"up"` / `"down"` / `"flat"` и окрашивает дельту в цвет роста, падения или нейтральный соответственно; без `trend` дельта обрабатывается как `flat`.

### Без дельты

Если `delta` опустить, значение занимает всю строку, а `trend` не действует; `description` тоже можно опустить.

```tsx
<StatCard label="在线设备" value="1,024" />
```

## Пропсы

| Prop          | Тип                        | По умолчанию | Описание                                                                    |
| ------------- | -------------------------- | ------------ | --------------------------------------------------------------------------- |
| `label`       | `string`                   | —            | Название метрики (обязателен)                                               |
| `value`       | `string`                   | —            | Значение метрики; форматирование — на стороне вызывающего кода (обязателен) |
| `delta`       | `string`                   | —            | Изменение к прошлому периоду, например `+12.5%`                             |
| `trend`       | `"up" \| "down" \| "flat"` | `"flat"`     | Направление окраски дельты, на остальное не влияет                          |
| `description` | `string`                   | —            | Поясняющий текст внизу, например период сравнения                           |
| `className`   | `string`                   | —            | Добавляется после имени класса компонента                                   |

## Доступность

StatCard несёт семантическую роль `group`, доступное имя берётся из `label`; метка, значение и дельта зачитываются вспомогательными технологиями по порядку как текст внутри группы. Если тренд выражен только цветом, убедитесь, что текст `delta` сам несёт направление (например, префикс `+`/`-`), и не полагайтесь только на красно-зелёную окраску.
