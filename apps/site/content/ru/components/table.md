# Table

Таблица с виртуальной прокруткой: определения колонок управляют и заголовком, и каждой строкой, поэтому десять тысяч строк обходятся так же дёшево, как один экран. Превью ниже рендерится движком pingo в реальном времени — его можно прокручивать, нажимать на строки, а также переключать светлую и тёмную тему.

:::

## Использование

`Table` — это чистая функция-конструктор, а не memo-компонент; при вызове она сразу возвращает узел сцены. Если вызывать её внутри области рендеринга компонента (как в функциональном компоненте ниже), чтение темы будет подписываться на переключение темы сайта.

```tsx
import type { PingoNode } from "@dopejs/pingo";
import { Table } from "@dopejs/pingo-ui";

type FileRow = { name: string; size: string };

function FileTable(): PingoNode {
  return Table<FileRow>({
    columns: [
      {
        key: "name",
        header: "Название",
        cell: (row) => <text value={row.name} />,
      },
      {
        key: "size",
        header: "Размер",
        width: 96,
        align: "end",
        cell: (row) => <text value={row.size} />,
      },
    ],
    rowCount: files.length,
    getRow: (index) => files[index],
    onRowPress: (index) => open(files[index]),
  });
}
```

Тело таблицы — это [VirtualList](/guide/scrolling), поэтому родительскому контейнеру нужно задать высоту (в примере у внешнего контейнера `height: 260`).

## Props

### TableProps\<Row\>

| Prop                 | Тип                                                      | По умолчанию   | Описание                                                                                 |
| -------------------- | -------------------------------------------------------- | -------------- | ---------------------------------------------------------------------------------------- |
| `columns`            | `readonly TableColumn<Row>[]`                            | —              | Определения колонок; управляют и заголовком, и строками (обязательно)                    |
| `rowCount`           | `number`                                                 | —              | Общее количество строк (обязательно); при `0` отображается пустое состояние              |
| `getRow`             | `(index: number) => Row`                                 | —              | Возвращает данные строки по её номеру; вызывается только для видимого окна (обязательно) |
| `estimatedRowHeight` | `number`                                                 | `44`           | Оценочная высота строки для планирования виртуальной прокрутки                           |
| `onRowPress`         | `(index: number) => void`                                | —              | Колбэк нажатия на строку; если передан, строки становятся фокусируемыми                  |
| `emptyLabel`         | `string`                                                 | `"Нет данных"` | Текст пустого состояния                                                                  |
| `renderHeaderCell`   | `(column: TableColumn<Row>, index: number) => PingoNode` | —              | Заменяет стандартную ячейку заголовка для конкретной колонки                             |
| `className`          | `string`                                                 | —              | Добавляется после имени класса компонента                                                |

### TableColumn\<Row\>

| Поле     | Тип                                      | По умолчанию | Описание                                                                                                  |
| -------- | ---------------------------------------- | ------------ | --------------------------------------------------------------------------------------------------------- |
| `key`    | `string`                                 | —            | Идентификатор колонки, используется как key узла (обязательно)                                            |
| `header` | `string`                                 | —            | Текст заголовка (обязательно)                                                                             |
| `width`  | `number`                                 | —            | Фиксированная ширина (в логических пикселях); если не указана, оставшаяся ширина распределяется по `flex` |
| `flex`   | `number`                                 | `1`          | Доля оставшейся ширины, когда `width` не задан                                                            |
| `align`  | `"start" \| "center" \| "end"`           | `"start"`    | Горизонтальное выравнивание содержимого; общее для заголовка и ячеек                                      |
| `cell`   | `(row: Row, index: number) => PingoNode` | —            | Функция построения содержимого ячейки (обязательно)                                                       |

Виртуальная таблица не может измерять ширину колонок по содержимому: неотрендеренные строки не участвуют в измерениях, поэтому ширина берётся только из определений колонок — благодаря этому заголовок и строки выравниваются естественным образом.

## Доступность

Таблица имеет семантику `table`, заголовки объявляются как `columnheader`, каждая строка — как `row`; если передан `onRowPress`, строки можно фокусировать указателем и активировать. Подробнее см. в [руководстве по доступности](/guide/accessibility).
