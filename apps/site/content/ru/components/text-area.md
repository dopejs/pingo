# Text Area

Многострочный ввод текста — для заметок, биографий и другого длинного содержимого. Превью ниже рендерится движком pingo в реальном времени — после щелчка можно по-настоящему вводить многострочный текст; превью переключается между светлой и тёмной темой вслед за темой сайта.

:::preview text-area-basic
:::

## Использование

```tsx
import { TextArea } from "@dopejs/pingo-ui";

root.render(
  <TextArea
    semanticLabel="个人简介"
    width={360}
    rows={4}
    onValueChange={(value) => console.log(value)}
  />,
);
```

`rows` задаёт число видимых строк и фиксирует минимальную высоту оболочки (`rows × высота строки + верхний и нижний внутренние отступы`). Как и [Input](/components/input), `TextArea` нужно монтировать как компонент через JSX. Подробности редактирования — в [руководстве по редактированию текста](/guide/editing).

## Примеры

### Отключённое состояние

С переданным `disabled` поле перестаёт принимать ввод и получает стили отключённого состояния.

## Пропсы

| Prop            | Тип                                      | По умолчанию | Описание                                                                                |
| --------------- | ---------------------------------------- | ------------ | --------------------------------------------------------------------------------------- |
| `value`         | `string`                                 | `""`         | Начальное значение для неконтролируемого режима; игнорируется при заданном `controller` |
| `onValueChange` | `(value: string) => void`                | —            | Колбэк с новейшим значением после применения каждой транзакции редактирования           |
| `controller`    | `TextEditingController`                  | —            | Продвинутый аварийный выход: постоянный контроллер на стороне вызывающего кода          |
| `onTransaction` | `(transaction: EditTransaction) => void` | —            | Сырой колбэк каждой транзакции редактирования                                           |
| `onSubmit`      | `() => void`                             | —            | Колбэк отправки                                                                         |
| `disabled`      | `boolean`                                | `false`      | Отключённое состояние                                                                   |
| `readOnly`      | `boolean`                                | `false`      | Состояние «только чтение»                                                               |
| `rows`          | `number`                                 | —            | Число видимых строк; определяет минимальную высоту оболочки                             |
| `className`     | `string`                                 | —            | Добавляется после имени класса компонента                                               |
| `width`         | `number`                                 | —            | Фиксированная ширина (px)                                                               |
| `semanticLabel` | `string`                                 | —            | Доступное имя                                                                           |

## Доступность

Давайте имя полю через `semanticLabel`; и `disabled`, и `readOnly` выводят поле из последовательности редактирования. Разделяет с Input известный пробел: пока нет ни текста-заполнителя, ни стиля кольца фокуса.
