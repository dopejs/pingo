# Toast

Toast — это легковесное уведомление, которое ненадолго появляется в углу. Подходит для мгновенной обратной связи: успешное сохранение, ошибка синхронизации и т.п. Превью ниже рендерится движком pingo в реальном времени — нажмите кнопку, чтобы вызвать toast; оформление следует за светлой/тёмной темой сайта.

## Использование

Toast нужно использовать вместе с `ToastViewport`. Вьюпорт — это абсолютно позиционированный контейнер в углу (по умолчанию справа сверху), и его **обязательно размещать в контейнере, близком к корню** — в этом движке содержащим блоком является родительский узел, а не ближайший позиционированный предок, поэтому если поместить его в маленький контейнер, он перекроет только этот маленький контейнер.

```tsx
import { Button, Toast, ToastViewport } from "@dopejs/pingo-ui";

let open = false;

function scene() {
  return (
    <container width={surfaceWidth} height={surfaceHeight}>
      <Button
        onPress={() => {
          open = true;
          root.render(scene());
        }}
      >
        Сохранить
      </Button>
      <ToastViewport>
        <Toast open={open} title="Сохранено" description="Конфигурация записана локально." />
      </ToastViewport>
    </container>
  );
}
```

Показ/скрытие и момент автоматического закрытия контролирует само приложение: достаточно переключить `open` и заново вызвать `root.render(...)` (кнопка в превью работает именно по этой схеме).

## Примеры

### Варианты

`variant="destructive"` используется для уведомлений об ошибках. В этом случае текст описания больше не использует приглушённый цвет переднего плана — разрушительный фон уже инвертировал передний план, и дополнительное приглушение дало бы серый текст на красном фоне.

## Props

### Toast

| Prop          | Тип                          | По умолчанию | Описание                                                              |
| ------------- | ---------------------------- | ------------ | --------------------------------------------------------------------- |
| `open`        | `boolean`                    | —            | Показывать ли toast; при `false` рендерится как `null` (обязательный) |
| `title`       | `string`                     | —            | Заголовок (обязательный)                                              |
| `description` | `string`                     | —            | Текст описания; если не указан, строка описания не рендерится         |
| `variant`     | `"default" \| "destructive"` | `"default"`  | Визуальный вариант                                                    |
| `className`   | `string`                     | —            | Добавляется после имени класса компонента                             |

### ToastViewport

| Prop        | Тип         | По умолчанию | Описание                                                                                                    |
| ----------- | ----------- | ------------ | ----------------------------------------------------------------------------------------------------------- |
| `children`  | `PingoNode` | —            | Список toast внутри вьюпорта; несколько уведомлений складываются по вертикали с отступом 8px (обязательный) |
| `className` | `string`    | —            | Добавляется после имени класса компонента                                                                   |

## Доступность

Toast имеет семантическую роль `status`, поэтому вспомогательные технологии озвучивают его как сообщение о состоянии. Toast не перехватывает текущий фокус; для результатов критически важных действий дополнительно сохраняйте на странице постоянную обратную связь (например, `Alert`).
