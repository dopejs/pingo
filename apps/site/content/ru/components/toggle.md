# Toggle

Двухпозиционная кнопка-переключатель: одно нажатие включает состояние, повторное — выключает. Превью ниже рендерится движком pingo в реальном времени — состояние можно переключать нажатием, превью переключается между светлой и тёмной темой вслед за темой сайта.

:::preview toggle-basic
:::

## Использование

```tsx
import { Toggle } from "@dopejs/pingo-ui";

root.render(
  <Toggle defaultPressed onPressedChange={(pressed) => console.log(pressed)}>
    加粗
  </Toggle>,
);
```

`Toggle` хранит состояние внутри через hooks, поэтому его нужно монтировать как компонент через JSX. Передача `pressed` переводит компонент в контролируемый режим; иначе используйте `defaultPressed`, чтобы компонент хранил состояние сам.

## Примеры

### Отключённое состояние

С переданным `disabled` кнопка перестаёт реагировать на указатель и клавиатуру и больше не активируется клавишами Enter/Пробел.

## Пропсы

| Prop              | Тип                          | По умолчанию | Описание                                       |
| ----------------- | ---------------------------- | ------------ | ---------------------------------------------- |
| `children`        | `string`                     | —            | Текст кнопки (обязателен)                      |
| `pressed`         | `boolean`                    | —            | Контролируемое нажатое состояние               |
| `defaultPressed`  | `boolean`                    | `false`      | Неконтролируемое изначальное нажатое состояние |
| `onPressedChange` | `(pressed: boolean) => void` | —            | Колбэк переключения состояния                  |
| `disabled`        | `boolean`                    | `false`      | Отключённое состояние                          |
| `className`       | `string`                     | —            | Добавляется после имени класса компонента      |

## Доступность

Компонент несёт семантику button, его семантическое значение переключается между `on` / `off`. При нажатии указателем фокус устанавливается автоматически; активация возможна клавишами `Enter` и `Пробел`.
