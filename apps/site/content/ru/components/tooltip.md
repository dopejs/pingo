# Tooltip

Tooltip показывает небольшой пояснительный текст при наведении указателя, по умолчанию привязанный сверху от цели. Превью ниже рендерится движком pingo в реальном времени — наведите указатель на кнопку, чтобы увидеть всплывающий балун; он переключается между светлой и тёмной темой вслед за темой сайта.

:::preview tooltip-basic
:::

## Использование

```tsx
import { createElement } from "@dopejs/pingo";
import { Button, Tooltip } from "@dopejs/pingo-ui";

root.render(
  createElement(Tooltip, {
    content: "保存到云端",
    children: createElement(Button, { children: "保存", onPress: () => save() }),
  }),
);
```

Tooltip управляется входом и уходом указателя (`pointerenter` / `pointerleave`) и не имеет контролируемых пропсов; при статическом рендеринге виден только триггер, а балун появляется при наведении.

## Пропсы

| Prop        | Тип         | По умолчанию | Описание                                           |
| ----------- | ----------- | ------------ | -------------------------------------------------- |
| `content`   | `string`    | —            | Текст балуна (обязателен)                          |
| `children`  | `PingoNode` | —            | Элемент-триггер (обязателен)                       |
| `className` | `string`    | —            | Добавляется после имени класса якорного контейнера |

## Доступность

Балун несёт семантику tooltip. Tooltip появляется только при наведении и не реагирует на фокус с клавиатуры; не помещайте критически важную информацию исключительно в Tooltip.
