# TopBar

TopBar — продуктовая молекула, специфичная для pingo: она объединяет заголовок и два слота — `leading` (логотип, назад) и `actions` (кнопки, аватар) — в строку верхней панели приложения. Колонка заголовка всегда занимает оставшееся место (`flexGrow`), прижимая actions к правому краю — без каких-либо измерений. Превью ниже рендерится движком pingo в реальном времени и переключается между светлой и тёмной темой вслед за темой сайта.

:::preview topbar-basic
:::

Связь с базовыми компонентами shadcn: TopBar сам не предоставляет ни кнопок, ни аватара — он задаёт **скелет раскладки**; слоты `leading` и `actions` принимают любой `PingoNode` и обычно комбинируются с [Button](/components/button), IconButton, Avatar и другими базовыми компонентами. Несколько action-элементов оберните в container с `flexDirection: "row"` и передайте одним узлом.

## Использование

```tsx
import { Avatar, Button, TopBar } from "@dopejs/pingo-ui";

root.render(
  <TopBar
    title="仪表盘"
    leading={<Avatar fallback="P" size={28} />}
    actions={
      <Button variant="outline" onPress={() => create()}>
        新建
      </Button>
    }
  />,
);
```

## Примеры

### Без заголовка

Если `title` опустить, колонка заголовка всё равно рендерится (пустой растягивающийся столбец), и actions по-прежнему прижимаются к правому краю — подходит для панелей инструментов только с операциями.

```tsx
<TopBar actions={<Button onPress={() => {}}>导出</Button>} />
```

## Пропсы

| Prop        | Тип         | По умолчанию | Описание                                                                |
| ----------- | ----------- | ------------ | ----------------------------------------------------------------------- |
| `title`     | `string`    | —            | Текст заголовка; если опущен, рендерится пустой растягивающийся столбец |
| `leading`   | `PingoNode` | —            | Передний слот — для логотипа или кнопки «назад»                         |
| `actions`   | `PingoNode` | —            | Задний слот, прижимаемый колонкой заголовка к правому краю              |
| `className` | `string`    | —            | Добавляется после имени класса компонента                               |

## Доступность

TopBar несёт семантическую роль `banner`; при заданном `title` текст заголовка получает роль `heading`. За доступные свойства компонентов внутри слотов (например, `semanticLabel` у IconButton) отвечает каждый компонент сам.
