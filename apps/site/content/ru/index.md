## Освоение за 30 секунд

```sh
pnpm add @dopejs/pingo
```

```ts
import { createElement, createHostedCanvasRoot } from "@dopejs/pingo";

const root = await createHostedCanvasRoot(document.querySelector("canvas")!);

root.render(
  createElement("virtualList", {
    width: 480,
    height: 640,
    itemCount: 1_000_000,
    estimatedItemHeight: 32,
    renderItem: (index) => createElement("text", { value: `第 ${index} 行` }),
  }),
);
```

Миллион строк не материализуется на стороне Shell, а прокрутка не вызывает обращений к дереву компонентов — расчёт окна и заполнение пропусков происходят внутри Core.

## Чего он не делает

Pingo — это движок рендеринга, а не браузер. Он **не занимается** SSR/первичным отображением HTML, общей совместимостью с CSS (блочная модель, каскад, селекторы),
адаптационными слоями для мини-приложений или нативных платформ, а также бизнес-семантикой rich text (совместное редактирование, формулы, Markdown-команды).

Движок **действительно владеет** caret, выделением, IME, буфером обмена, undo/redo и примитивами редактируемого текста — это не отдаётся обратно бизнес-слою
для сборки из DOM-элементов.

Производительность на реальных устройствах, реальные методы ввода, скринридеры и матрица энергопотребления мультимедиа относятся к сбору квалификации платформы и отслеживаются отдельно;
визуальная навигация с учётом bidi и включение WebGPU-бэкенда по умолчанию остаются [задокументированными отложенными пунктами](https://github.com/dopejs/pingo/blob/main/docs/plan.md).
