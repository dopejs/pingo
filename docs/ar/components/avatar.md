# Avatar

يعرض Avatar الصورة الرمزية للمستخدم: عند تمرير مورد صورة مفكوك الترميز، تُعرض مقصوصة بشكل دائري، وعند عدم التمرير، تعود إلى اختصار `fallback`. تُعرض المعاينة أدناه مباشرةً بواسطة محرك pingo، وتتبع تبديل السمة بين الفاتح والداكن.

:::preview avatar-basic
:::

## الاستخدام

```tsx
import { createElement } from "@dopejs/pingo";
import { Avatar } from "@dopejs/pingo-ui";

root.render(createElement(Avatar, { fallback: "张" }));
```

عند توفر صورة، مرِّر مورد `PingoImage` مفكوك الترميز مسبقًا، حيث تُملأ الصورة وتُقصّ دائريًا باستخدام `object-fit: cover`:

```tsx
createElement(Avatar, { image: decodedImage, fallback: "张" });
```

## أمثلة

### الحجم

`size` هو طول ضلع المربع (بالبكسل)، مع ضبط نصف قطر الانحناء على `size / 2`. عند الإغفال، يُستخدم الحجم الافتراضي للقالب وهو 40 بكسل. تظهر المعاينة بالترتيب: 32، الافتراضي، 56.

```tsx
createElement(Avatar, { fallback: "李", size: 32 });
```

## Props

| Prop | النوع | القيمة الافتراضية | الوصف |
| --- | --- | --- | --- |
| `image` | `PingoImage` | — | مورد صورة مفكوك الترميز مسبقًا؛ عند غيابه يُعرض اختصار `fallback` |
| `fallback` | `string` | — | نص الاختصار، يُعرض عند فقدان الصورة (مطلوب) |
| `size` | `number` | الافتراضي للقالب `40` | طول ضلع المربع (بالبكسل) |
| `className` | `string` | — | يُضاف بعد اسم فئة المكوّن |

## إمكانية الوصول

يؤدي اختصار `fallback` أيضًا دور الاسم المقروء، لذا استخدم أحرفًا تمثل المستخدم (مثل اسم العائلة أو الأحرف الأولى من الاسم)، ولا تمرر رموزًا نائبة.
