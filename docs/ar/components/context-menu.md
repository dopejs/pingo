# قائمة السياق

تفتح قائمة السياق عند النقر بزر الفأرة الأيمن (حدث `contextmenu`) على المنطقة المستهدفة، وذلك عند موضع المؤشر. تُعرض المعاينة أدناه مباشرةً بواسطة محرك pingo — انقر بزر الفأرة الأيمن على منطقة النص لفتح القائمة، وتتبع السمة الفاتحة/الداكنة الخاصة بالموقع.

:::preview context-menu-basic
:::

## الاستخدام

```tsx
import { createElement } from "@dopejs/pingo";
import { ContextMenu } from "@dopejs/pingo-ui";

root.render(
  createElement(ContextMenu, {
    items: [
      { value: "copy", label: "نسخ" },
      { value: "paste", label: "لصق", disabled: true },
      { value: "delete", label: "حذف" },
    ],
    onSelect: (value) => run(value),
    children: createElement("text", { value: "انقر بزر الفأرة الأيمن هنا" }),
  }),
);
```

تُوضع القائمة عند موضع ضغط المؤشر وليس عند زاوية العنصر المُطلق؛ وتُغلق عند الضغط على `Escape` أو بعد اختيار عنصر. لا تشارك العناصر المعطلة في التنقل بلوحة المفاتيح، ولا تستجيب للنقر. عند العرض الثابت تظهر منطقة الإطلاق فقط، وتظهر القائمة عند النقر بزر الفأرة الأيمن.

## Props

| Prop           | النوع                         | القيمة الافتراضية | الوصف                                |
| -------------- | ----------------------------- | ----------------- | ------------------------------------ |
| `children`     | `PingoNode`                   | —                 | محتوى منطقة الإطلاق (مطلوب)          |
| `items`        | `readonly ContextMenuEntry[]` | —                 | عناصر القائمة (مطلوب)                |
| `onSelect`     | `(value: string) => void`     | —                 | استدعاء عند اختيار عنصر من القائمة   |
| `onOpenChange` | `(open: boolean) => void`     | —                 | استدعاء عند تغير حالة الفتح والإغلاق |
| `className`    | `string`                      | —                 | اسم فئة إضافي                        |

### ContextMenuEntry

| الحقل      | النوع     | القيمة الافتراضية | الوصف                     |
| ---------- | --------- | ----------------- | ------------------------- |
| `value`    | `string`  | —                 | قيمة عنصر القائمة (مطلوب) |
| `label`    | `string`  | —                 | النص المعروض (مطلوب)      |
| `disabled` | `boolean` | `false`           | حالة التعطيل              |

## إمكانية الوصول

تتمتع القائمة بدلالات menu، وتتمتع عناصرها بدلالات menuitem؛ بعد الفتح يمكن التنقل لأعلى ولأسفل بمفاتيح الأسهم، وتُغلق بالضغط على `Escape`.
