# منتقي التاريخ

منتقي التاريخ هو [تقويم](/components/calendar) مرتبط بقيمة: مُطلق مع تقويم شهري منبثق. المعاينة أدناه تُعرض مباشرة بواسطة محرك pingo — التقويم مفتوح بالفعل، ويمكن التنقل بين الصفحات، وتحديد التواريخ، ومتابعة تبديل السمة بين الفاتح والداكن.

:::preview date-picker-basic
:::

## الاستخدام

```tsx
import { createElement } from "@dopejs/pingo";
import { DatePicker, type CalendarDate } from "@dopejs/pingo-ui";

root.render(
  createElement(DatePicker, {
    placeholder: "اختر تاريخًا",
    onSelect: (date: CalendarDate) => console.log(date),
  }),
);
```

يُمثَّل التاريخ بنوع `CalendarDate` (`{ year, month, day }`) — يُخزَّن في حقول منفصلة، فلا يمكن لأي منطقة زمنية أن تزيحه يومًا كاملًا. بعد تحديد التاريخ يُغلق المنبثق تلقائيًا: فإبقاء المنتقي مفتوحًا يحوّله إلى مجرد تقويم.

## أمثلة

### التنسيق والنص البديل

يعرض المُطلق التاريخ المحدد افتراضيًا بصيغة `YYYY-MM-DD`؛ يتيح `format` تخصيص العرض، بينما يخصّص `placeholder` النص البديل عند عدم وجود تحديد.

### الفتح والإغلاق المتحكَّم بهما

يشكّل `open` مع `onOpenChange` تحكمًا كاملًا في حالة الفتح والإغلاق؛ وعند غيابهما يدير المكوّن حالة الفتح والإغلاق ذاتيًا.

## الخصائص

| الخاصية         | النوع                             | القيمة الافتراضية                      | الوصف                                         |
| --------------- | --------------------------------- | -------------------------------------- | --------------------------------------------- |
| `value`         | `CalendarDate`                    | —                                      | التاريخ المحدد                                |
| `month`         | `CalendarDate`                    | —                                      | الشهر المعروض المُتحكَّم به                   |
| `defaultMonth`  | `CalendarDate`                    | `value ?? 2026-01-01`                  | الشهر الابتدائي غير المُتحكَّم به             |
| `onSelect`      | `(date: CalendarDate) => void`    | —                                      | استدعاء عند تحديد تاريخ (يُغلق تلقائيًا بعده) |
| `onMonthChange` | `(month: CalendarDate) => void`   | —                                      | استدعاء عند التنقل بين الأشهر                 |
| `weekdayLabels` | `readonly string[]`               | `["日","一","二","三","四","五","六"]` | ترويسة أيام الأسبوع                           |
| `monthLabel`    | `(month: CalendarDate) => string` | —                                      | تخصيص عنوان الشهر                             |
| `isDisabled`    | `(date: CalendarDate) => boolean` | —                                      | تعطيل تواريخ محددة                            |
| `open`          | `boolean`                         | —                                      | حالة الفتح والإغلاق المُتحكَّم بها            |
| `onOpenChange`  | `(open: boolean) => void`         | —                                      | استدعاء عند تغيير حالة الفتح والإغلاق         |
| `placeholder`   | `string`                          | `"اختر تاريخًا"`                       | النص البديل عند عدم وجود تحديد                |
| `format`        | `(date: CalendarDate) => string`  | `formatDate` (`YYYY-MM-DD`)            | عرض التاريخ على المُطلق                       |
| `className`     | `string`                          | —                                      | يُضاف بعد اسم فئة المكوّن                     |

## إمكانية الوصول

يحمل المُطلق دلالات زر ويتبدل بين `expanded` و`collapsed`؛ بينما يرث جزء التقويم دلالات الشبكة من مكوّن Calendar. عند فتح المنبثق ينتقل التركيز إلى اللوحة، وعند إغلاقه يعود إلى المُطلق.
