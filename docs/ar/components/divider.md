# Divider

يوفر الفاصل تجميعًا مرئيًا بين المحتويات. تُعرض المعاينة أدناه مباشرة بواسطة محرك pingo، وتتبع سمة الموقع للتبديل بين الوضعين الفاتح والداكن.

:::preview divider-horizontal
:::

## الاستخدام

```tsx
import { createElement } from "@dopejs/pingo";
import { Divider } from "@dopejs/pingo-ui";

root.render(createElement(Divider, {}));
```

## أمثلة

### فاصل رأسي

بتمرير `orientation: "vertical"` تحصل على فاصل رأسي. يكون ارتفاع الفاصل الرأسي 100% من ارتفاع الحاوية الأصل، لذا يجب أن يكون للحاوية الأصل ارتفاع محدد.

:::preview divider-vertical
:::

## Props

| Prop | النوع | القيمة الافتراضية | الوصف |
| --- | --- | --- | --- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | اتجاه الفاصل |
| `className` | `string` | — | يُضاف بعد اسم فئة المكوّن |

يكون عرض الفاصل الأفقي 100% من عرض الحاوية الأصل وارتفاعه 1px؛ ويكون ارتفاع الفاصل الرأسي 100% من ارتفاع الحاوية الأصل وعرضه 1px.

## إمكانية الوصول

Divider عنصر بصري خالص لا يحمل دورًا دلاليًا، وتتجاهله التقنيات المساعدة؛ وينبغي التعبير عن تجميع المحتوى عبر بنى دلالية مثل العناوين.
