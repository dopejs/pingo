# Form

`Form` هو حاوية النموذج، بينما يجمع `FormField` التسمية والعنصر ورسائل الخطأ/الوصف في حقل واحد. المعاينة أدناه تُعرض مباشرة بواسطة محرك pingo——يمكن تحرير حقول الإدخال فيها فعليًا، وتتبع تبديل السمة الفاتحة/الداكنة للموقع.

:::preview form-basic
:::

## الاستخدام

```tsx
import { createElement } from "@dopejs/pingo";
import { Form, FormField, Input } from "@dopejs/pingo-ui";

root.render(
  createElement(Form, {
    children: createElement(FormField, {
      label: "البريد الإلكتروني",
      required: true,
      error: emailError, // قواعد التحقق يملكها الطرف المستدعي
      children: createElement(Input, {
        semanticLabel: "البريد الإلكتروني",
        onValueChange: (value) => validate(value),
      }),
    }),
  }),
);
```

التحقق ليس داخل المكوّن: متى يتم التحقق، وما الخطأ الذي يُعرض، وكيفية التجميع كلها قرارات منتج. الطرف المستدعي يملك القواعد ويمرر `error`، والمكوّن مسؤول فقط عن التخطيط والدلالات ومواضع المعلومات.

## أمثلة

### الخطأ والوصف

عند وجود `error` يُعلَّم الحقل بأنه غير صالح، و**يستبدل** نص الوصف——إذا كان أحد السطرين الإرشاديين رسالة فشل، فسيطغى عليه السطر الآخر. `required` يلحق علامة `*` بعد التسمية.

## Props

### Form

| Prop        | النوع       | القيمة الافتراضية | الوصف                     |
| ----------- | ----------- | ----------------- | ------------------------- |
| `children`  | `PingoNode` | —                 | محتوى النموذج (مطلوب)     |
| `className` | `string`    | —                 | يُلحق بعد اسم فئة المكوّن |

### FormField

| Prop          | النوع       | القيمة الافتراضية | الوصف                                                             |
| ------------- | ----------- | ----------------- | ----------------------------------------------------------------- |
| `label`       | `string`    | —                 | تسمية الحقل (مطلوب)                                               |
| `children`    | `PingoNode` | —                 | عنصر الحقل (مطلوب)                                                |
| `error`       | `string`    | —                 | رسالة الخطأ؛ عند وجودها يُعلَّم الحقل بأنه غير صالح وتستبدل الوصف |
| `description` | `string`    | —                 | نص وصفي مساعد                                                     |
| `required`    | `boolean`   | `false`           | علامة الإلزامية، تلحق `*` بعد التسمية                             |
| `className`   | `string`    | —                 | يُلحق بعد اسم فئة المكوّن                                         |

## إمكانية الوصول

يحمل `Form` دورًا دلاليًا `form`؛ ويحمل `FormField` دلالة `group` ويُسمَّى بالتسمية، وعند عدم الصلاحية تكون القيمة الدلالية `invalid`. تُوضع العلامات الدلالية على المجموعة لا على العنصر——العنصر ملك للطرف المستدعي، والمجموعة هي العنصر الوحيد المضمون وجوده.
