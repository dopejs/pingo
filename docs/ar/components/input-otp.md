# Input OTP

إدخال رمز تحقق لمرة واحدة، يتكون من عدة خلايا بطول ثابت. المعاينة التالية تُرسم مباشرة بواسطة محرك pingo — يمكنك إدخال الأرقام خلية بخلية، ولصق رمز التحقق كاملاً، ومتابعة تبديل السمة الفاتحة والداكنة مع سمة الموقع.

:::preview input-otp-basic
:::

## الاستخدام

```tsx
import { createElement } from "@dopejs/pingo";
import { InputOTP } from "@dopejs/pingo-ui";

root.render(
  createElement(InputOTP, {
    length: 6,
    semanticLabel: "رمز التحقق لمرة واحدة",
    onValueChange: (value) => console.log(value),
    onComplete: (code) => verify(code),
  }),
);
```

القيمة الداخلية هي **سلسلة بطول ثابت تُستكمل بمسافات**: المسافة تمثل موضعًا فارغًا. يستقبل `onValueChange` هذه القيمة المستكملة؛ ويعمل `onComplete` مرة واحدة عند امتلاء جميع الخلايا، ويستقبل رمز التحقق الكامل بعد إزالة المسافات. يُعامل اللصق كتعبئة كاملة تبدأ من الخلية الحالية، بينما يمسح الحذف الخلية الحالية فقط دون إزاحة الأرقام اللاحقة إلى اليسار.

## أمثلة

### الطول

يحدد `length` عدد الخلايا (الافتراضي 6). تستخدم كل خلية لوحة مفاتيح رقمية برمجية (`inputMode: "numeric"`).

## Props

| Prop            | النوع                     | القيمة الافتراضية | الوصف                                                                          |
| --------------- | ------------------------- | ----------------- | ------------------------------------------------------------------------------ |
| `length`        | `number`                  | `6`               | عدد الخلايا                                                                    |
| `value`         | `string`                  | —                 | القيمة الحالية المُتحكم بها (مستكملة بمسافات)                                  |
| `defaultValue`  | `string`                  | —                 | القيمة الابتدائية غير المُتحكم بها                                             |
| `onValueChange` | `(value: string) => void` | —                 | استدعاء عند تغير القيمة، وتكون القيمة سلسلة بطول ثابت مستكملة بمسافات          |
| `onComplete`    | `(value: string) => void` | —                 | استدعاء عند الامتلاء الكامل، وتكون القيمة رمز التحقق الكامل بعد إزالة المسافات |
| `disabled`      | `boolean`                 | `false`           | تعطيل جميع الخلايا                                                             |
| `semanticLabel` | `string`                  | —                 | الاسم الميسَّر للمجموعة                                                        |
| `className`     | `string`                  | —                 | يُضاف بعد اسم فئة المكوّن                                                      |

## إمكانية الوصول

يحمل المكوّن دورًا دلاليًا `group`؛ وتحصل كل خلية تلقائيًا على اسم ميسَّر بصيغة `الرقم/الإجمالي` (مثل `3/6`)، كما يمكن تسمية المجموعة كاملة عبر `semanticLabel`.
