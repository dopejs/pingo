# ListRow

ListRow هو جزيء منتج خاص بـ pingo: صف عنصر قائمة، يحتل العنوان والوصف العمود المرن الأوسط، بينما يتوزع فتحتا `leading` (الصورة الرمزية، الأيقونة) و`trailing` (الشارة، المفتاح، السهم) على الطرفين. تُعرض المعاينة أدناه مباشرةً بواسطة محرك pingo — فالصفوف القابلة للنقر تمتلك تغذية راجعة كاملة للمؤشر، وتتبع تبديل السمة الفاتحة والداكنة في الموقع.

:::preview list-row-basic
:::

علاقة التركيب مع عناصر shadcn الأساسية: يحدد ListRow تخطيط الصف وحالات التفاعل، ولا يضمّن أي مكوّن محتوى داخليًا؛ تقبل فتحتا `leading`/`trailing` أي `PingoNode`، والتركيبات النموذجية هي Avatar أو Badge أو Switch. عند الحاجة إلى مسافة بين الصفوف المتجاورة، استخدم حاوية بارتفاع ثابت للتباعد (لا توجد خاصية gap في pingo).

## الاستخدام

```tsx
import { createElement } from "@dopejs/pingo";
import { Avatar, Badge, ListRow } from "@dopejs/pingo-ui";

root.render(
  createElement(ListRow, {
    title: "张三",
    description: "zhangsan@example.com",
    leading: createElement(Avatar, { fallback: "张", size: 32 }),
    trailing: createElement(Badge, { children: "管理员" }),
    onPress: () => openMember("zhangsan"),
  }),
);
```

## أمثلة

### التحديد والتعطيل

يطبّق `selected` نمط التحديد ويكشف حالة التحديد للخارج؛ أما الصفوف ذات `disabled` فلا تحمل أي معالجات أحداث — وهذا أقوى من «التحقق داخل المعالج».

:::preview list-row-states
:::

### صف عرض خالص

عند عدم تمرير `onPress` يكون السلوك عنصر عرض خالصًا: الدور الدلالي هو `listitem`، دون أنماط تفاعل أو أحداث.

## Props

| Prop | النوع | القيمة الافتراضية | الوصف |
| --- | --- | --- | --- |
| `title` | `string` | — | نص العنوان (مطلوب) |
| `description` | `string` | — | نص الوصف الثانوي |
| `leading` | `PingoNode` | — | فتحة أمامية لوضع الصورة الرمزية أو الأيقونة |
| `trailing` | `PingoNode` | — | فتحة خلفية لوضع الشارة أو المفتاح أو السهم |
| `selected` | `boolean` | — | حالة التحديد؛ عند تمريرها تُكشف القيمتان الدلاليتان `selected`/`unselected` |
| `disabled` | `boolean` | `false` | حالة التعطيل، لا تُسجَّل أي معالجات أحداث |
| `onPress` | `() => void` | — | رد نداء النقر؛ عند تمريره يصبح الصف قابلًا للتفاعل |
| `className` | `string` | — | يُلحق بعد اسم فئة المكوّن |

## إمكانية الوصول

تمتلك الصفوف القابلة للتفاعل دورًا دلاليًا `button`، أما صفوف العرض الخالص فدورها `listitem`؛ ويُؤخذ الاسم الميسَّر من `title`. عند تمرير `selected` تُكشف القيمتان الدلاليتان `selected`/`unselected`. لا تحمل الصفوف المعطلة أي معالجات مؤشر/لوحة مفاتيح، وتظهر للتقنيات المساعدة كعناصر ثابتة خالصة.
