# ترقيم الصفحات

عنصر تحكم لترقيم الصفحات: يتم تمييز الصفحة الحالية، وتُطوى سلاسل أرقام الصفحات الطويلة تلقائيًا إلى علامات حذف، ويُعطَّل السهم المقابل عند الوصول إلى الصفحة الأولى/الأخيرة. المعاينة أدناه تُعرض لحظيًا بواسطة محرك pingo — يمكنك النقر على أرقام الصفحات والأسهم للتنقل بين الصفحات، ويتغير المظهر بين الفاتح والداكن تبعًا لسمة الموقع.

:::

## الاستخدام

رقم الصفحة **مُتحكَّم به**: يبدأ `page` من 1، ويُبلَّغ عن تغيير الصفحة عبر `onPageChange`، وتقوم أنت بإعادة كتابته.

```tsx
import { createElement, useSignal, type PingoNode } from "@dopejs/pingo";
import { Pagination } from "@dopejs/pingo-ui";

function PagedList(): PingoNode {
  const page = useSignal(1);
  return createElement(Pagination, {
    page: page.get(),
    pageCount: 12,
    onPageChange: (next) => page.set(next),
  });
}
```

## أمثلة

### الوضع المضغوط

يتحكم `siblingCount` في عدد أرقام الصفحات المعروضة على جانبي الصفحة الحالية (باستثناء الصفحة الأولى والأخيرة، فالأولى والأخيرة تُعرضان دائمًا). عند ضبطه على `0` تُعرض الصفحة الأولى والأخيرة والصفحة الحالية فقط؛ ويكون سهم الصفحة السابقة معطلًا عند التواجد في الصفحة الأولى.

:::preview pagination-compact
:::

قواعد طي سلسلة أرقام الصفحات تُنفَّذ بواسطة الدالة النقية المُصدَّرة `paginationRange(page, pageCount, siblingCount)`، ويمكن استخدامها منفردة لأغراض الاختبار.

## Props

| Prop            | النوع                    | القيمة الافتراضية | الوصف                                                                                                 |
| --------------- | ------------------------ | ----------------- | ----------------------------------------------------------------------------------------------------- |
| `page`          | `number`                 | —                 | الصفحة الحالية، تبدأ من 1 (إلزامي)؛ يتم تقييد القيم الخارجة عن النطاق إلى `[1, pageCount]`            |
| `pageCount`     | `number`                 | —                 | إجمالي عدد الصفحات (إلزامي)؛ عند أقل من 1 لا يُعرض أي رقم صفحة                                        |
| `onPageChange`  | `(page: number) => void` | —                 | رد نداء تغيير الصفحة؛ لا يُستدعى عند النقر على الصفحة الحالية أو على هدف خارج النطاق                  |
| `siblingCount`  | `number`                 | `1`               | عدد أرقام الصفحات المعروضة على كل جانب من الصفحة الحالية                                              |
| `previousLabel` | `string`                 | —                 | نص الصفحة السابقة المحجوز في النوع؛ في الإصدار الحالي يُعرض كأيقونة، وهذا الحقل لا يشارك في العرض بعد |
| `nextLabel`     | `string`                 | —                 | نص الصفحة التالية المحجوز في النوع؛ في الإصدار الحالي يُعرض كأيقونة، وهذا الحقل لا يشارك في العرض بعد |
| `className`     | `string`                 | —                 | يُضاف بعد اسم فئة المكوّن                                                                             |

## إمكانية الوصول

يحمل عنصر التحكم عمومًا دلالة `navigation`؛ والصفحة الحالية تحمل القيمة الدلالية `current`، والأسماء الدلالية لأزرار التنقل للصفحة السابقة/التالية هي "previous page" / "next page"، وعند الوصول إلى الحدود تُعطَّل ولا تستجيب للمؤشر. على لوحة المفاتيح يقوم `ArrowLeft` / `ArrowRight` بتغيير الصفحة من أي نقطة تركيز داخل عنصر التحكم. للمزيد راجع [دليل إمكانية الوصول](/guide/accessibility).
