# منطقة التمرير

تعمل منطقة التمرير على تمرير المحتوى الطويل جدًا داخل إطار عرض ثابت الحجم، وترسم شريط تمرير متسقًا مع السمة. المعاينة أدناه تُعرض مباشرة بواسطة محرك pingo — جرّب التمرير فوق القائمة.

:::preview scroll-area-basic
:::

## الاستخدام

```tsx
import { createElement } from "@dopejs/pingo";
import { ScrollArea } from "@dopejs/pingo-ui";

root.render(
  createElement(ScrollArea, {
    children: items.map((item) => createElement("text", { value: item })),
  }),
);
```

يبلغ عرض المكوّن وارتفاعه 100% من الحاوية الأصل، ويتطلب حاوية أصل ذات أبعاد محددة؛ ولا يظهر شريط التمرير إلا عندما يتجاوز المحتوى إطار العرض.

## Props

| Prop | النوع | القيمة الافتراضية | الوصف |
| --- | --- | --- | --- |
| `children` | `PingoNode` | — | محتوى التمرير (مطلوب) |
| `hideScrollbar` | `boolean` | `false` | إخفاء شريط التمرير المرسوم (مع بقاء القدرة على التمرير) |
| `className` | `string` | — | يُلحق بعد اسم فئة المكوّن |

## إمكانية الوصول

يوفّر محرك Core سلوك التمرير، ويحافظ إطار العرض على قابلية التركيز والتمرير بلوحة المفاتيح. يُشتق شريط التمرير من القياس الهندسي الفعلي لإطار العرض والمحتوى، وقد يتأخر مقبض شريط التمرير إطارًا واحدًا عند السحب السريع.

لسلوكيات المحرك المتعلقة بالتمرير، انظر [دليل التمرير](/guide/scrolling).
