# Skeleton

يعرض Skeleton كتلًا نائبة قريبة الشكل من التخطيط النهائي قبل اكتمال تحميل المحتوى، مما يقلل من الإحساس بالقفز أثناء الانتظار. المعاينة أدناه تُرسم مباشرة بواسطة محرك pingo، وتتبع فاتح/داكن حسب سمة الموقع.

:::preview skeleton-card
:::

## الاستخدام

```tsx
import { createElement } from "@dopejs/pingo";
import { Skeleton } from "@dopejs/pingo-ui";

root.render(createElement(Skeleton, { width: 320, height: 16 }));
```

يمكن حذف `width` / `height` معًا، وعندها تُترك الأبعاد بالكامل للتخطيط الخارجي وورقة الأنماط الخاصة بك.

## أمثلة

### التركيب في هيكل صفحة

استخدم عدة مكونات Skeleton بأحجام مختلفة لتشكيل بنية المحتوى القادم — المعاينة أعلاه هي هيكل بطاقة «صورة رمزية + عنوان + سطرا نص». لا يملك pingo خاصية gap، لذا تُنفَّذ المسافات بين الكتل عبر حاويات فارغة بأبعاد ثابتة، انظر [دليل الأنماط](/guide/styling).

## Props

| Prop | النوع | القيمة الافتراضية | الوصف |
| --- | --- | --- | --- |
| `width` | `number` | — | عرض الكتلة النائبة (px)، وعند الحذف يحدده التخطيط |
| `height` | `number` | — | ارتفاع الكتلة النائبة (px)، وعند الحذف يحدده التخطيط |
| `className` | `string` | — | يُضاف بعد اسم فئة المكوّن |

## إمكانية الوصول

Skeleton عنصر نائب تزييني بلا دلالة. عند اكتمال التحميل يجب استبداله كليًا بالمحتوى الحقيقي؛ والبقاء طويلًا على شاشة الهيكل يعني فشل التحميل، لذا قدّم رسالة خطأ ومدخلًا لإعادة المحاولة.

الوضع الحالي عنصر نائب ثابت (بلا حركة نبضية) — مجموعة الحركات الأساسية لا تدعم CSS keyframes بعد.
