# StatCard

StatCard هو جزيء منتج خاص بـ pingo: بلاطة مؤشر تتكون من تسمية وقيمة ودلتا دورية ونص توضيحي. يؤثر `trend` فقط على تلوين الدلتا — يبقي `flat` اللون الرمادي المحايد، لأن المؤشر المستقر لا يُعد جيدًا أو سيئًا. المعاينة أدناه تُرسَم لحظيًا بواسطة محرك pingo، وتتبع تبديل السمة الفاتحة/الداكنة للموقع.

:::preview statcard-basic
:::

علاقة التركيب مع مكونات shadcn الأساسية: StatCard جزيء عرض قائم بذاته، يستخدم داخليًا فقط بدائيات Text/View، ولا يحجز فتحات محتوى؛ عند تخطيط لوحة المعلومات يُستخدم عادةً حاوية ذات `flexDirection: "row"` لصف عدة بطاقات StatCard في سطر واحد، أو تُدمج مع Card وDivider لتكوين كتلة تقرير. تنسيق القيمة (فواصل الآلاف، رموز العملات) يقع على عاتق المستدعي، وكل من `value`/`delta` نصان خالصان.

## الاستخدام

```tsx
import { createElement } from "@dopejs/pingo";
import { StatCard } from "@dopejs/pingo-ui";

root.render(
  createElement(StatCard, {
    label: "إيرادات هذا الشهر",
    value: "¥128,400",
    delta: "+12.5%",
    trend: "up",
    description: "مقارنة بالشهر السابق",
  }),
);
```

## أمثلة

### تلوين الاتجاه

يأخذ `trend` القيم `"up"` / `"down"` / `"flat"`، فيلوّن الدلتا بألوان الصعود والهبوط والمحايد على الترتيب؛ وعند عدم تمرير `trend` تُعامل القيمة على أنها `flat`.

### بدون دلتا

عند حذف `delta` تحتل القيمة سطرًا بمفردها، ولا يسري `trend`؛ ويمكن حذف `description` أيضًا.

```tsx
createElement(StatCard, { label: "الأجهزة المتصلة", value: "1,024" });
```

## Props

| Prop | النوع | القيمة الافتراضية | الوصف |
| --- | --- | --- | --- |
| `label` | `string` | — | اسم المؤشر (مطلوب) |
| `value` | `string` | — | قيمة المؤشر، والتنسيق مسؤولية المستدعي (مطلوب) |
| `delta` | `string` | — | التغير الدوري، مثل `+12.5%` |
| `trend` | `"up" \| "down" \| "flat"` | `"flat"` | اتجاه تلوين الدلتا، ولا يؤثر على الأجزاء الأخرى |
| `description` | `string` | — | نص توضيحي سفلي، مثل فترة المقارنة |
| `className` | `string` | — | يُلحق بعد اسم فئة المكوّن |

## إمكانية الوصول

يمتلك StatCard دورًا دلاليًا `group`، ويُؤخذ الاسم الميسّر من `label`، وتقرأ التقنيات المساعدة التسمية والقيمة والدلتا بوصفها نصوصًا داخل المجموعة بالتتابع. عند التعبير عن الاتجاه باللون فقط، تأكد من أن نص `delta` يحمل في ذاته معلومات الاتجاه (مثل بادئة `+`/`-`)، ولا تعتمد على التلوين الأحمر/الأخضر وحده.
