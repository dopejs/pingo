# منطقة النص

إدخال نصي متعدد الأسطر، يُستخدم للملاحظات والنبذات التعريفية وغيرها من المحتويات الطويلة. تتم عملية العرض/الرسم في المعاينة التالية بشكل حي بواسطة محرك pingo — بعد النقر يمكنك إدخال نص متعدد الأسطر فعليًا، ويتغير المظهر بين الفاتح والداكن تبعًا لنسق الموقع.

:::preview text-area-basic
:::

## الاستخدام

```tsx
import { createElement } from "@dopejs/pingo";
import { TextArea } from "@dopejs/pingo-ui";

root.render(
  createElement(TextArea, {
    semanticLabel: "نبذة شخصية",
    width: 360,
    rows: 4,
    onValueChange: (value) => console.log(value),
  }),
);
```

يحدد `rows` عدد الأسطر المرئية ويثبّت الحد الأدنى لارتفاع الهيكل (`rows × ارتفاع السطر + الحشوة العلوية والسفلية`). وكما هو الحال مع [Input](/components/input)، يجب تركيب `TextArea` كمكوّن باستخدام `createElement`. لمزيد من تفاصيل التحرير راجع [دليل التحرير النصي](/guide/editing).

## أمثلة

### التعطيل

عند تمرير `disabled` يتوقف الحقل عن استقبال الإدخال، وتُطبَّق أنماط التعطيل.

## Props

| Prop            | النوع                                    | القيمة الافتراضية | الوصف                                                                       |
| --------------- | ---------------------------------------- | ----------------- | --------------------------------------------------------------------------- |
| `value`         | `string`                                 | `""`              | القيمة الأولية للاستخدام غير المُتحكَّم به؛ تُتجاهَل عند تعيين `controller` |
| `onValueChange` | `(value: string) => void`                | —                 | يُستدعى بأحدث قيمة بعد تطبيق كل معاملة تحرير                                |
| `controller`    | `TextEditingController`                  | —                 | منفذ احتياطي متقدم: متحكم دائم يحتفظ به المستدعي                            |
| `onTransaction` | `(transaction: EditTransaction) => void` | —                 | رد النداء الخام لكل معاملة تحرير                                            |
| `onSubmit`      | `() => void`                             | —                 | رد نداء الإرسال                                                             |
| `disabled`      | `boolean`                                | `false`           | حالة التعطيل                                                                |
| `readOnly`      | `boolean`                                | `false`           | حالة القراءة فقط                                                            |
| `rows`          | `number`                                 | —                 | عدد الأسطر المرئية، ويحدد الحد الأدنى لارتفاع الهيكل                        |
| `className`     | `string`                                 | —                 | يُضاف بعد اسم فئة المكوّن                                                   |
| `width`         | `number`                                 | —                 | عرض ثابت (px)                                                               |
| `semanticLabel` | `string`                                 | —                 | الاسم المُستخدَم في إمكانية الوصول                                          |

## إمكانية الوصول

قدّم اسم الحقل عبر `semanticLabel`؛ يعمل كلٌّ من `disabled` و`readOnly` على إخراج الحقل من تسلسل التحرير. توجد فجوات معروفة مشتركة مع Input: لا توجد حاليًا أنماط للنص المؤقت ولا لحلقة التركيز.
