# Toast

Toast هو إشعار خفيف يظهر لفترة وجيزة في الزاوية، مناسب للتغذية الراجعة الفورية مثل نجاح الحفظ أو فشل المزامنة. المعاينة أدناه تُعرض مباشرة بواسطة محرك pingo — انقر الزر لتشغيل toast، وسيتبع سمة الموقع للتبديل بين الوضعين الفاتح والداكن.

:::

## الاستخدام

يجب استخدام Toast مع `ToastViewport`. منفذ العرض هو حاوية زاوية بموضع مطلق (الزاوية العلوية اليمنى افتراضيًا)، **ويجب وضعه تحت حاوية قريبة من الجذر** — الكتلة الحاوية في هذا المحرك هي العقدة الأصل وليست أقرب سلف ذي موضع، فإذا وُضع داخل حاوية صغيرة فلن يغطي سوى تلك الحاوية الصغيرة.

```tsx
import { createElement } from "@dopejs/pingo";
import { Button, Toast, ToastViewport } from "@dopejs/pingo-ui";

let open = false;

function scene() {
  return createElement("container", {
    width: surfaceWidth,
    height: surfaceHeight,
    children: [
      createElement(Button, {
        children: "حفظ",
        onPress: () => {
          open = true;
          root.render(scene());
        },
      }),
      createElement(ToastViewport, {
        children: createElement(Toast, {
          open,
          title: "تم الحفظ",
          description: "تمت كتابة الإعدادات محليًا.",
        }),
      }),
    ],
  });
}
```

التحكم في الإظهار/الإخفاء وتوقيت الإغلاق التلقائي يعود للتطبيق نفسه: بدّل قيمة `open` وأعد استدعاء `root.render(...)` (الزر في المعاينة يعمل بهذا النمط).

## Props

### Toast

| Prop          | النوع                        | القيمة الافتراضية | الوصف                                                      |
| ------------- | ---------------------------- | ----------------- | ---------------------------------------------------------- |
| `open`        | `boolean`                    | —                 | ما إذا كان سيُعرض؛ عند `false` يُعرض كقيمة `null` (إلزامي) |
| `title`       | `string`                     | —                 | العنوان (إلزامي)                                           |
| `description` | `string`                     | —                 | نص الوصف؛ عند حذفه لا يُعرض سطر الوصف                      |
| `variant`     | `"default" \| "destructive"` | `"default"`       | النوع البصري                                               |
| `className`   | `string`                     | —                 | يُضاف بعد اسم فئة المكوّن                                  |

### ToastViewport

| Prop        | النوع       | القيمة الافتراضية | الوصف                                                            |
| ----------- | ----------- | ----------------- | ---------------------------------------------------------------- |
| `children`  | `PingoNode` | —                 | قائمة التوست داخل منفذ العرض، وتتكدس عموديًا بمسافة 8px (إلزامي) |
| `className` | `string`    | —                 | يُضاف بعد اسم فئة المكوّن                                        |

## إمكانية الوصول

يحمل Toast دورًا دلاليًا هو `status`، وستعلن التقنيات المساعدة عنه كرسالة حالة. لا يقاطع toast التركيز الحالي؛ ولنتائج العمليات الحرجة، يُرجى أيضًا الاحتفاظ بتغذية راجعة دائمة على الصفحة (مثل `Alert`).
