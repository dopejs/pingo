## الانطلاق في ٣٠ ثانية

```sh
pnpm add @dopejs/pingo
```

```ts
import { createElement, createHostedCanvasRoot } from "@dopejs/pingo";

const root = await createHostedCanvasRoot(document.querySelector("canvas")!);

root.render(
  createElement("virtualList", {
    width: 480,
    height: 640,
    itemCount: 1_000_000,
    estimatedItemHeight: 32,
    renderItem: (index) => createElement("text", { value: `第 ${index} 行` }),
  }),
);
```

مليون صفّ لا يُجسَّد في جهة الغلاف، ولا يردّ التمرير النداء إلى شجرة المكوّنات — حساب النافذة والبناء التعويضي يحدثان داخل النواة.

## ما لا يفعله

Pingo محرّك عرض لا متصفّح. **لا يفعل** SSR/HTML للعرض الأوّل، ولا توافق CSS عامًّا (نموذج الصندوق والتتالي والمحدِّدات)، ولا طبقات تكييف للتطبيقات المصغّرة أو المنصّات الأصيلة، ولا دلالات النصّ الغني على مستوى العمل (التعاون والصيغ وأوامر Markdown).

المحرّك **يملك فعلًا** المؤشّر النصّي والتحديد وIME والحافظة والتراجع والإعادة وبدائيات النصّ القابل للتحرير — هذه لن تُدفَع إلى طبقة العمل لتُرقَّع بعناصر DOM.

## الحالة الراهنة

اكتملت جميع المعالم الهندسية P0–M8؛ واكتمل تخطيط M9 «الأهلية للإنتاج والتركيب التزايدي وتصليب الإصدار» ولم يبدأ تنفيذه بعد، انظر [خطة M9](/m9-production-plan). تغييرات المستودع الحالية ما زالت تحت Unreleased ولا تعني صدور نسخة npm جديدة.

أداء الأجهزة الحقيقية وطرق الإدخال الفعلية وقارئات الشاشة ومصفوفة استهلاك الطاقة تدخل في جمع أهلية المنصّة وتُتابَع كلٌّ على حدة؛ أمّا التنقّل البصري ثنائي الاتجاه (bidi) والتفعيل الافتراضي لخلفية WebGPU فما زالا [بندَين مؤجَّلَين موثَّقَين](/plan).
