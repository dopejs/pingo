# Skeleton

Skeleton מציג בלוקים למילוי מקום שצורתם קרובה לפריסה הסופית לפני שהתוכן מסתיים להיטען, ומפחית את תחושת הקפיצה בזמן ההמתנה. התצוגה המקדימה שלהלן מרונדרת בזמן אמת על ידי מנוע pingo ועוקבת אחר ערכת הנושא של האתר למעבר בין מצב בהיר לכהה.

:::preview skeleton-card
:::

## שימוש

```tsx
import { createElement } from "@dopejs/pingo";
import { Skeleton } from "@dopejs/pingo-ui";

root.render(createElement(Skeleton, { width: 320, height: 16 }));
```

ניתן להשמיט גם את `width` וגם את `height` — במקרה כזה הממדים נקבעים במלואם על ידי הפריסה החיצונית וגיליון הסגנונות שלך.

## דוגמאות

### הרכבת שלד עמוד

השתמשו במספר רכיבי Skeleton בגדלים שונים כדי לבנות את מבנה התוכן שעומד להופיע — התצוגה המקדימה למעלה היא שלד כרטיס מסוג "אווטאר + כותרת + שתי שורות טקסט". ל-pingo אין מאפיין gap, ולכן הריווח בין בלוקים נעשה באמצעות מיכל ריק בגודל קבוע — ראו [מדריך הסגנונות](/guide/styling).

## Props

| Prop | טיפוס | ברירת מחדל | תיאור |
| --- | --- | --- | --- |
| `width` | `number` | — | רוחב בלוק המילוי (px), נקבע על ידי הפריסה אם הושמט |
| `height` | `number` | — | גובה בלוק המילוי (px), נקבע על ידי הפריסה אם הושמט |
| `className` | `string` | — | מצורף לאחר שם המחלקה של הרכיב |

## נגישות

Skeleton הוא רכיב מילוי דקורטיבי ללא משמעות סמנטית. לאחר סיום הטעינה יש להחליפו כולו בתוכן אמיתי; שהייה ממושכת על מסך שלד מעידה על כשל בטעינה — נא להציג הודעת שגיאה ואפשרות לניסיון חוזר.

כרגע מדובר במילוי סטטי (ללא אנימציית פעימה) — תת-קבוצת האנימציה הבסיסית אינה תומכת עדיין ב-CSS keyframes.
