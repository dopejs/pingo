# Changelog

バージョン方針は `docs/release.md` を参照してください。12 パッケージを同一バージョンで
アトミックに公開し、npm の semver とバイナリ ABI のバージョンは独立して管理します。

## 0.3.1 - 2026-08-25

- `@dopejs/pingo-ui` を npm に公開するようにしました。バージョンはエンジンと同じです。これまでは
  リポジトリとドキュメントにあるだけで公開対象に入っておらず、46 個のコンポーネントに文書は
  あってもインストールできませんでした。公開対象に入れたことで、必須ファイル・ライセンス
  ファイル・workspace 依存の書き換え・依存関係の閉包という成果物検証も働くようになります。

## 0.3.0 - 2026-08-25

- 仮想リストの項目がリスト全体に引き伸ばされるようになり、テーブル本体の行がヘッダーの
  列と揃います。ラッパーのレイアウトは Core が持ち、スタイルのカスケードを通りません。
- スクロールコンテナ内で引き伸ばされたボックスが、確定した交差サイズとパーセント基準を
  取り戻しました。スクロールパネル内のボックスが内容幅に戻ることはなくなり、仮想項目内の
  `100%` がゼロになることもありません。
- flex 項目にブロック軸方向の CSS 自動最小サイズが入りました。非常に大きな兄弟要素が、
  内容でサイズが決まる項目をゼロまで潰すことはなくなります。CSS サブセット 1.8.0 で
  `min-width`/`min-height` の初期値が `auto` になりました。
- コンポーネント: Skeleton が脈動します。NavigationMenu は Menubar の枠を使わなくなり
  シェブロンが付きます。テーブルのヘッダーは縮まなくなりました。StatCard/TopBar/ListRow
  は幅を指定せずにマウントしても内容幅を保ちます。
- リリース: npm への公開対象と成果物一覧は検証器のパッケージ一覧から導出されます。
  再現ビルドの検証はゲートの最後に移りました。
- 0.3.0 からプロジェクトのライセンスを MIT から Apache-2.0 に変更します。
  公開済みの v0.2.1 以前のバージョンは引き続き MIT ライセンスです。

## 0.2.1 - 2026-08-20

- `initializeWasm` を公開しました。冪等で再試行可能なので、アプリケーション側で WASM の
  読み込みを組み立てられます。Storybook の読み込み表示は軽量な遅延表示になり、Worker の
  初期化も同じ入口を使います。
- 二つのクロックの Playground は、ページを開いた時点から百万行の仮想スクロールを続けます。
  ボタンはメインスレッドを塞ぐだけで、スクロール状態の開始やリセットは行いません。
- Core/Worker のクロックが保持する等速のプログラム的スクロール `setScrollVelocity` を
  追加しました。Input Stream に対応するコマンドが加わり、ABI バージョンは 10 から 11 に
  上がりました。

## 0.2.0 - 2026-08-20

- ホイールの伝達カーブをブラウザネイティブに合わせました。離散的なホイールノッチは
  アニメーションでスクロールし、高精度（トラックパッド）デルタは 1:1 で即座に適用します。
  Input Stream の `DispatchEvent` に flags フィールドを追加し、ABI バージョンは 1 → 2 になりました。
- 公式サイトが簡体字中国語、繁体字中国語、スペイン語、フランス語、ドイツ語、ロシア語、
  ヘブライ語、アラビア語、日本語、韓国語に対応しました。

## 0.1.0

最初の公開可能なリリースです。P0–M5 のエンジニアリングマイルストーンをすべて完了し、
`pnpm m5:check`（M0→M5 の全自動ゲート）が全て通過しています。

- 決定的な Rust/WASM Core + TypeScript Shell：単一のスキーマ、バージョン管理された
  Mutation/Input/DisplayList/逆方向ストリーム、不正入力のアトミックな拒否。
- デュアルクロックのレンダリング：SAB → postMessage → メインスレッド Canvas2D の
  フォールバックチェーン。メインスレッドが 200ms ブロックされても Worker が描画を継続します。
- ネイティブな仮想スクロール（100 万行で P95/P99 サブマイクロ秒の再生）とテキストサブシステム
  （明示的なフォントシェーピング、グリフアトラス、システムフォントのフォールバック）。
- canvas ネイティブな編集：EditContext と入力プロキシの二経路、IME 変換、ポインタと
  キーボードでのキャレット移動、クリップボード、undo/redo、パスワードマスク、
  キャレットの scroll-into-view。
- ヒットテスト（差分 BVH + 素朴なオラクルによるプロパティテスト）と capture/target/bubble の
  3 フェーズイベント、非 passive 領域の同期 `preventDefault` プロトコル。
- アクセシビリティ：セマンティクスツリーの書き出し、DOM シャドウツリーの反映、`getByRole` による
  セマンティック E2E セレクタ、キーボードフォーカスの転送。
- 移行と本番化：`@dopejs/pingo-compat` によるページ単位の段階適用とロールバック、移行スキャナ、
  リリースパッケージと WASM の SHA-256 完全性検証、診断と運用手順書。
- 隔離された WebGPU プロトタイプとヘッドレスオラクルとのゼロ不一致差分（ADR-0006：
  Continue Experiment、既定は無効）。

明示的な先送り：bidi の視覚的キャレット移動、ウィジェットのプレースホルダー、WebGPU の既定有効化。
プラットフォーム認定（実機性能、実際の IME、スクリーンリーダー）は別途追跡し、パッケージの
バージョンでは約束しません。
