# Skeleton

Skeleton は、コンテンツの読み込み完了前に最終レイアウトに近い形状のプレースホルダーブロックを表示し、待機時のレイアウトシフトを軽減します。以下のプレビューは pingo エンジンによりリアルタイムで描画され、サイトのテーマに合わせてライト／ダークが切り替わります。

:::preview skeleton-card
:::

## 使い方

```tsx
import { createElement } from "@dopejs/pingo";
import { Skeleton } from "@dopejs/pingo-ui";

root.render(createElement(Skeleton, { width: 320, height: 16 }));
```

`width` / `height` はどちらも省略可能です。省略した場合、サイズは外側のレイアウトとスタイルシートに完全に委ねられます。

## 例

### ページスケルトンとして組み合わせる

サイズの異なる複数の Skeleton を組み合わせて、これから表示されるコンテンツ構造を作ります。上記のプレビューは「アバター＋タイトル＋2行の本文」というカードスケルトンです。pingo には gap プロパティがないため、ブロック間の余白は固定サイズの空コンテナで実現します。詳しくは[スタイルガイド](/guide/styling)を参照してください。

## Props

| Prop | 型 | デフォルト値 | 説明 |
| --- | --- | --- | --- |
| `width` | `number` | — | プレースホルダーブロックの幅（px）。省略時はレイアウトにより決定 |
| `height` | `number` | — | プレースホルダーブロックの高さ（px）。省略時はレイアウトにより決定 |
| `className` | `string` | — | コンポーネントのクラス名の後に追加 |

## アクセシビリティ

Skeleton は装飾的なプレースホルダーであり、セマンティクスを持ちません。読み込み完了後は実際のコンテンツに丸ごと置き換えるべきです。スケルトン画面が長時間表示され続ける場合は読み込み失敗を意味するため、エラーメッセージと再試行の導線を提示してください。

現在は静的なプレースホルダー（パルスアニメーションなし）です。コアアニメーションサブセットでは現時点で CSS keyframes をサポートしていません。
