# Avatar

Avatar показывает аватар пользователя: если передан декодированный ресурс изображения, он отображается с круглой обрезкой, иначе используется откат к аббревиатуре `fallback`. Превью ниже рендерится движком pingo в реальном времени и переключается между светлой и тёмной темой вслед за темой сайта.

:::preview avatar-basic
:::

## Использование

```tsx
import { createElement } from "@dopejs/pingo";
import { Avatar } from "@dopejs/pingo-ui";

root.render(createElement(Avatar, { fallback: "张" }));
```

Если изображение есть, передайте предварительно декодированный ресурс `PingoImage`: оно заполняется в режиме `object-fit: cover` и обрезается в круг:

```tsx
createElement(Avatar, { image: decodedImage, fallback: "张" });
```

## Примеры

### Размеры

`size` — длина стороны квадрата (px); радиус скругления при этом устанавливается в `size / 2`. Если опустить, используется скиновское значение по умолчанию 40px. В превью показаны подряд 32, значение по умолчанию и 56.

```tsx
createElement(Avatar, { fallback: "李", size: 32 });
```

## Пропсы

| Prop | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `image` | `PingoImage` | — | Предварительно декодированный ресурс изображения; без него показывается аббревиатура `fallback` |
| `fallback` | `string` | — | Текст аббревиатуры, показываемый при отсутствии изображения (обязателен) |
| `size` | `number` | скиновское `40` | Длина стороны квадрата (px) |
| `className` | `string` | — | Добавляется после имени класса компонента |

## Доступность

Аббревиатура `fallback` одновременно выполняет роль читаемого имени: используйте символы, представляющие пользователя (например, фамилию или инициалы), и не передавайте placeholder-знаки.
