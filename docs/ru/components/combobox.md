# Combobox

Комбобокс связывает триггер, показывающий выбранное значение, с поисковым списком вариантов. Превью ниже рендерится движком pingo в реальном времени — список развёрнут: можно вводить текст для фильтрации и выбирать клавишами-стрелками; превью переключается между светлой и тёмной темой вслед за темой сайта.

## Использование

```tsx
import { createElement } from "@dopejs/pingo";
import { Combobox } from "@dopejs/pingo-ui";

root.render(
  createElement(Combobox, {
    items: [
      { value: "next", label: "Next.js" },
      { value: "remix", label: "Remix" },
      { value: "astro", label: "Astro" },
    ],
    placeholder: "选择框架",
    onValueChange: (value) => console.log(value),
  }),
);
```

`items` — массив `{ value, label }`; фильтрация — регистронезависимое совпадение подстроки по `label`, нечёткое ранжирование намеренно не делается: плохая сортировка хуже её отсутствия. После выбора список сворачивается автоматически, а поисковый запрос очищается **при закрытии** — чтобы при повторном открытии не остался давно забытый фильтр.

## Примеры

### Контролируемый режим

И `value` / `onValueChange`, и `open` / `onOpenChange` могут быть контролируемыми; если их не задать, компонент хранит состояние сам через `defaultValue` / `defaultOpen`.

### Пустое состояние

`emptyLabel` задаёт текст, показываемый, когда фильтрация не дала результатов.

## Пропсы

| Prop | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `items` | `readonly { value: string; label: string }[]` | — | Список вариантов (обязателен) |
| `value` | `string` | — | Контролируемое выбранное значение |
| `defaultValue` | `string` | — | Неконтролируемое начальное выбранное значение |
| `onValueChange` | `(value: string) => void` | — | Колбэк изменения выбора (после выбора список сворачивается) |
| `open` | `boolean` | — | Контролируемое открытие |
| `defaultOpen` | `boolean` | `false` | Неконтролируемое начальное открытие |
| `onOpenChange` | `(open: boolean) => void` | — | Колбэк открытия/закрытия |
| `placeholder` | `string` | `"请选择"` | Текст-заполнитель на триггере, пока ничего не выбрано |
| `emptyLabel` | `string` | — | Подсказка при пустом результате фильтрации |
| `className` | `string` | — | Добавляется после имени класса компонента |

## Доступность

Триггер несёт семантику button и переключается между `expanded` / `collapsed`. При открытии списка фокус переходит в строку поиска, стрелки двигают подсветку, Enter выбирает и закрывает; после закрытия фокус возвращается к триггеру.
