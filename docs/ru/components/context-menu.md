# Context Menu

Context Menu открывает меню в позиции указателя при щелчке правой кнопкой по целевой области (событие `contextmenu`). Превью ниже рендерится движком pingo в реальном времени — щёлкните правой кнопкой по текстовой области, чтобы открыть меню; превью переключается между светлой и тёмной темой вслед за темой сайта.

:::

## Использование

```tsx
import { createElement } from "@dopejs/pingo";
import { ContextMenu } from "@dopejs/pingo-ui";

root.render(
  createElement(ContextMenu, {
    items: [
      { value: "copy", label: "复制" },
      { value: "paste", label: "粘贴", disabled: true },
      { value: "delete", label: "删除" },
    ],
    onSelect: (value) => run(value),
    children: createElement("text", { value: "在此右键" }),
  }),
);
```

Меню позиционируется в точке нажатия указателя, а не у угла триггера; закрывается по `Escape` или после выбора пункта. Отключённые пункты не участвуют в навигации с клавиатуры и не реагируют на щелчки. При статическом рендеринге видна только область-триггер, меню появляется по правому щелчку.

## Пропсы

| Prop           | Тип                           | По умолчанию | Описание                                  |
| -------------- | ----------------------------- | ------------ | ----------------------------------------- |
| `children`     | `PingoNode`                   | —            | Содержимое области-триггера (обязательно) |
| `items`        | `readonly ContextMenuEntry[]` | —            | Пункты меню (обязателен)                  |
| `onSelect`     | `(value: string) => void`     | —            | Колбэк выбора пункта меню                 |
| `onOpenChange` | `(open: boolean) => void`     | —            | Колбэк открытия/закрытия                  |
| `className`    | `string`                      | —            | Добавочное имя класса                     |

### ContextMenuEntry

| Поле       | Тип       | По умолчанию | Описание                          |
| ---------- | --------- | ------------ | --------------------------------- |
| `value`    | `string`  | —            | Значение пункта меню (обязателен) |
| `label`    | `string`  | —            | Отображаемый текст (обязателен)   |
| `disabled` | `boolean` | `false`      | Отключённое состояние             |

## Доступность

Меню несёт семантику menu, пункты — семантику menuitem; после открытия стрелки двигают вверх/вниз, `Escape` закрывает.
