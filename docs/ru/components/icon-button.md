# Icon Button

Кнопка-иконка служит для компактных действий без текстовой метки. Превью ниже рендерится движком pingo в реальном времени — её можно нажимать и фокусировать, она переключается между светлой и тёмной темой вслед за темой сайта.

:::preview icon-button-basic
:::

## Использование

```tsx
import { createElement } from "@dopejs/pingo";
import { IconButton } from "@dopejs/pingo-ui";

root.render(
  createElement(IconButton, {
    icon: createElement("text", { value: "★" }),
    semanticLabel: "收藏",
    variant: "outline",
    onPress: () => toggleFavorite(),
  }),
);
```

`icon` — сквозной слот, принимающий любой `PingoNode`: иконочный шрифт, SVG или текстовый глиф. Поскольку видимого текста нет, `semanticLabel` обязателен.

## Примеры

### Варианты

`variant` полностью совпадает с [Button](/components/button): `default`, `secondary`, `outline`, `ghost`, `destructive`.

### Известные ограничения

`size` поддерживает `default`, `sm`, `lg`, но в текущем скине нет составных правил `sm`/`lg` для варианта icon: размер иконки перекрывает модификатор размера, поэтому `sm`/`lg` пока не дают визуального эффекта.

## Пропсы

| Prop            | Тип                                                                 | По умолчанию | Описание                                       |
| --------------- | ------------------------------------------------------------------- | ------------ | ---------------------------------------------- |
| `icon`          | `PingoNode`                                                         | —            | Слот иконки, передаётся как есть (обязателен)  |
| `semanticLabel` | `string`                                                            | —            | Доступное имя (обязателен)                     |
| `variant`       | `"default" \| "secondary" \| "outline" \| "ghost" \| "destructive"` | `"default"`  | Визуальный вариант                             |
| `size`          | `"default" \| "sm" \| "lg"`                                         | `"default"`  | Размер (`sm`/`lg` пока не действуют, см. выше) |
| `disabled`      | `boolean`                                                           | `false`      | Отключённое состояние                          |
| `onPress`       | `() => void`                                                        | —            | Колбэк активации указателем/клавиатурой        |
| `className`     | `string`                                                            | —            | Добавляется после имени класса компонента      |

## Доступность

У кнопки-иконки нет видимого текста, и скринридер может полагаться только на `semanticLabel` — поэтому этот проп обязателен. Кнопка несёт семантику button и поддерживает активацию с клавиатуры.
