# Input

Однострочный ввод текста. Предпросмотр ниже рендерится движком pingo в реальном времени — после клика можно по-настоящему вводить, выделять и удалять текст, а также переключать светлую и тёмную тему вместе с сайтом.

:::preview input-basic
:::

## Использование

```tsx
import { createElement } from "@dopejs/pingo";
import { Input } from "@dopejs/pingo-ui";

root.render(
  createElement(Input, {
    semanticLabel: "邮箱",
    width: 320,
    onValueChange: (value) => console.log(value),
  }),
);
```

`Input` внутренне поддерживает стабильный `TextEditingController` через hooks, поэтому его нужно монтировать как компонент с помощью `createElement(Input, props)`, а не вызывать напрямую как функцию. Подробнее о редактировании см. в [руководстве по редактированию текста](/guide/editing).

## Примеры

### Префикс, суффикс и пароль

Слоты `prefix`/`suffix` позволяют разместить иконки или единицы измерения; `password` включает маскированный ввод; `disabled` блокирует всё поле.

:::preview input-adornments
:::

### Управляемое использование

Передача собственного `controller` переводит компонент в управляемый режим: в этом случае `value` игнорируется как начальное значение, а вызывающая сторона владеет контроллером и сохраняет один и тот же экземпляр между рендерами.

## Props

| Prop | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `value` | `string` | `""` | Начальное значение для неуправляемого использования; игнорируется при заданном `controller` |
| `onValueChange` | `(value: string) => void` | — | Вызывается с последним значением после применения каждой транзакции редактирования |
| `controller` | `TextEditingController` | — | Продвинутый запасной вариант: постоянный контроллер, которым владеет вызывающая сторона |
| `onTransaction` | `(transaction: EditTransaction) => void` | — | Исходный обратный вызов для каждой транзакции редактирования |
| `onSubmit` | `() => void` | — | Обратный вызов отправки (Enter) |
| `disabled` | `boolean` | `false` | Заблокированное состояние |
| `readOnly` | `boolean` | `false` | Состояние только для чтения |
| `password` | `boolean` | `false` | Маскированный ввод |
| `inputMode` | `"decimal" \| "email" \| "none" \| "numeric" \| "search" \| "tel" \| "text" \| "url"` | `"text"` | Подсказка раскладки программной клавиатуры |
| `className` | `string` | — | Добавляется после имени класса компонента |
| `width` | `number` | — | Фиксированная ширина (px) |
| `semanticLabel` | `string` | — | Имя для доступности |
| `prefix` | `PingoNode` | — | Переднее украшение, например иконка или символ валюты |
| `suffix` | `PingoNode` | — | Заднее украшение, например единица измерения или кнопка очистки |

## Доступность

Имя поля задаётся через `semanticLabel`; `disabled` и `readOnly` выводят поле из последовательности редактирования. Известные на данный момент пробелы: пока нет текста-заполнителя (placeholder) и стилей кольца фокуса.
