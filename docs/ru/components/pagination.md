# Pagination

Пагинация: текущая страница подсвечена, слишком длинная последовательность номеров автоматически сворачивается в многоточие, а на первой/последней странице соответствующая стрелка отключается. Превью ниже рендерится движком pingo в реальном времени — можно щёлкать по номерам и стрелкам для перелистывания; превью переключается между светлой и тёмной темой вслед за темой сайта.

:::

## Использование

Номер страницы — **контролируемый**: `page` начинается с 1, перелистывание сообщается через `onPageChange`, а записываете его обратно вы.

```tsx
import { createElement, useSignal, type PingoNode } from "@dopejs/pingo";
import { Pagination } from "@dopejs/pingo-ui";

function PagedList(): PingoNode {
  const page = useSignal(1);
  return createElement(Pagination, {
    page: page.get(),
    pageCount: 12,
    onPageChange: (next) => page.set(next),
  });
}
```

## Примеры

### Компактный режим

`siblingCount` задаёт число номеров по обе стороны от текущей страницы (не считая первой и последней, они показываются всегда). При значении `0` остаются только первая, последняя и текущая; на первой странице стрелка «назад» отключена.

:::preview pagination-compact
:::

Правила сворачивания последовательности номеров реализованы экспортируемой чистой функцией `paginationRange(page, pageCount, siblingCount)` — её можно тестировать отдельно.

## Пропсы

| Prop | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `page` | `number` | — | Текущая страница, начиная с 1 (обязателен); значения вне диапазона сводятся к `[1, pageCount]` |
| `pageCount` | `number` | — | Общее число страниц (обязателен); при значении меньше 1 номера не рендерятся |
| `onPageChange` | `(page: number) => void` | — | Колбэк перелистывания; щелчок по текущей странице или цели вне диапазона его не вызывает |
| `siblingCount` | `number` | `1` | Число номеров по обе стороны от текущей страницы |
| `previousLabel` | `string` | — | Зарезервированный в типе текст кнопки «назад»; в текущей версии рендерится иконка, и поле пока не участвует в рендеринге |
| `nextLabel` | `string` | — | Зарезервированный в типе текст кнопки «вперёд»; в текущей версии рендерится иконка, и поле пока не участвует в рендеринге |
| `className` | `string` | — | Добавляется после имени класса компонента |

## Доступность

Весь контрол несёт семантику `navigation`; текущая страница имеет семантическое значение `current`, доступные имена кнопок перелистывания — "previous page" / "next page", на границах они отключены и не реагируют на указатель. С клавиатуры `ArrowLeft` / `ArrowRight` листают страницы при любом фокусе внутри контрола. Подробнее — в [руководстве по доступности](/guide/accessibility).
