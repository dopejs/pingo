# Scroll Area

Scroll Area прокручивает слишком длинное содержимое внутри вьюпорта фиксированного размера и рисует полосу прокрутки, согласованную с темой. Превью ниже рендерится движком pingo в реальном времени — попробуйте прокрутить список.

:::preview scroll-area-basic
:::

## Использование

```tsx
import { createElement } from "@dopejs/pingo";
import { ScrollArea } from "@dopejs/pingo-ui";

root.render(
  createElement(ScrollArea, {
    children: items.map((item) => createElement("text", { value: item })),
  }),
);
```

Компонент занимает 100% ширины и высоты родительского контейнера и требует родителя с определёнными размерами; полоса прокрутки появляется только когда содержимое выходит за пределы вьюпорта.

## Props

| Prop | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `children` | `PingoNode` | — | Прокручиваемое содержимое (обязательно) |
| `hideScrollbar` | `boolean` | `false` | Скрыть рисуемую полосу прокрутки (возможность прокрутки сохраняется) |
| `className` | `string` | — | Добавляется к имени класса компонента |

## Доступность

Прокрутка обеспечивается ядром движка; вьюпорт сохраняет фокусируемость и прокрутку с клавиатуры. Полоса прокрутки выводится из измеренной геометрии вьюпорта и содержимого, поэтому при быстром перетаскивании её ползунок может отставать на один кадр.

О поведении движка, связанном с прокруткой, см. [руководство по прокрутке](/guide/scrolling).
