# Skeleton

Skeleton показывает до завершения загрузки содержимого блоки-заполнители, близкие по форме к итоговой раскладке, и снижает ощущение скачков во время ожидания. Превью ниже рендерится движком pingo в реальном времени и переключает светлую и тёмную тему вместе с темой сайта.

:::preview skeleton-card
:::

## Использование

```tsx
import { createElement } from "@dopejs/pingo";
import { Skeleton } from "@dopejs/pingo-ui";

root.render(createElement(Skeleton, { width: 320, height: 16 }));
```

`width` и `height` можно опустить — тогда размеры полностью определяются внешней раскладкой и вашей таблицей стилей.

## Примеры

### Сборка скелета страницы

Из нескольких Skeleton разных размеров составляется структура будущего содержимого — превью выше как раз представляет собой карточку-скелет «аватар + заголовок + две строки текста». В pingo нет свойства gap: интервалы между блоками делаются пустыми контейнерами фиксированного размера, см. [руководство по стилям](/guide/styling).

## Props

| Prop | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `width` | `number` | — | Ширина блока-заполнителя (px); если опущена, определяется раскладкой |
| `height` | `number` | — | Высота блока-заполнителя (px); если опущена, определяется раскладкой |
| `className` | `string` | — | Добавляется к имени класса компонента |

## Доступность

Skeleton — декоративный заполнитель и не несёт семантики. После завершения загрузки его следует целиком заменить настоящим содержимым; долгое отображение скелета означает сбой загрузки — покажите сообщение об ошибке и кнопку повтора.

Сейчас заполнитель статичен (без пульсирующей анимации) — ядро пока не поддерживает подмножество CSS-анимаций с keyframes.
