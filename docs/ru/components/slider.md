# Slider

Ползунок служит для выбора числового значения в диапазоне. Превью ниже рендерится движком pingo в реальном времени — ползунок можно перетаскивать или точно настраивать клавишами-стрелками; превью переключается между светлой и тёмной темой вслед за темой сайта.

:::preview slider-basic
:::

## Использование

```tsx
import { createElement } from "@dopejs/pingo";
import { Slider } from "@dopejs/pingo-ui";

root.render(
  createElement(Slider, {
    defaultValue: 40,
    min: 0,
    max: 100,
    step: 1,
    semanticLabel: "音量",
    onValueChange: (value) => console.log(value),
  }),
);
```

`Slider` хранит состояние перетаскивания внутри через hooks, поэтому его нужно монтировать как компонент через `createElement`. Передача `value` переводит компонент в контролируемый режим; иначе используйте `defaultValue`, чтобы компонент хранил состояние сам.

## Примеры

### Диапазон и шаг

`min` / `max` ограничивают диапазон значений (по умолчанию 0–100), `step` задаёт гранулярность настройки с клавиатуры (по умолчанию 1).

### Отключённое состояние

С переданным `disabled` ползунок перестаёт реагировать на перетаскивание и клавиатуру.

## Пропсы

| Prop | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `value` | `number` | — | Контролируемое текущее значение |
| `defaultValue` | `number` | `min` | Неконтролируемое начальное значение |
| `onValueChange` | `(value: number) => void` | — | Колбэк изменения значения |
| `min` | `number` | `0` | Минимальное значение |
| `max` | `number` | `100` | Максимальное значение |
| `step` | `number` | `1` | Шаг с клавиатуры |
| `disabled` | `boolean` | `false` | Отключённое состояние |
| `semanticLabel` | `string` | — | Доступное имя |
| `className` | `string` | — | Добавляется после имени класса компонента |

## Доступность

Компонент несёт семантическую роль `slider`, семантическое значение — строковая форма текущего числа. `←`/`↓` уменьшают значение на один `step`, `→`/`↑` увеличивают, `Home`/`End` переводят к концам диапазона; значение всегда ограничивается внутри `[min, max]`.
