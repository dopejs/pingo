# Switch

Переключатель служит для булевых настроек, применяемых мгновенно. Превью ниже рендерится движком pingo в реальном времени и переключается между светлой и тёмной темой вслед за темой сайта. Switch — контролируемый компонент: в превью показана статическая комбинация вкл/выкл/отключён, а интерактивность задаётся состоянием на стороне вызывающего кода.

## Использование

```tsx
import { createElement, useSignal, type PingoNode } from "@dopejs/pingo";
import { Switch } from "@dopejs/pingo-ui";

// useSignal 是 hook，必须运行在组件作用域内。
function AirplaneMode(): PingoNode {
  const on = useSignal(false);
  return createElement(Switch, {
    checked: on.get(),
    semanticLabel: "飞行模式",
    onCheckedChange: (next) => on.set(next),
  });
}

root.render(createElement(AirplaneMode));
```

`checked` хранится в родительском компоненте, а `onCheckedChange` обновляет его — сам компонент состояния не хранит.

## Примеры

### Отключённое состояние

С переданным `disabled` переключатель перестаёт реагировать на указатель и клавиатуру, а семантическое значение становится `disabled`.

## Пропсы

| Prop              | Тип                          | По умолчанию | Описание                                             |
| ----------------- | ---------------------------- | ------------ | ---------------------------------------------------- |
| `checked`         | `boolean`                    | —            | Состояние переключателя (обязателен, контролируемый) |
| `onCheckedChange` | `(checked: boolean) => void` | —            | Колбэк переключения состояния                        |
| `disabled`        | `boolean`                    | `false`      | Отключённое состояние                                |
| `className`       | `string`                     | —            | Добавляется после имени класса компонента            |
| `semanticLabel`   | `string`                     | —            | Доступное имя                                        |

## Доступность

Компонент несёт семантическую роль `switch`, его семантическое значение переключается между `on` / `off` / `disabled`. При нажатии указателем фокус устанавливается автоматически. У переключателя нет видимого текста — всегда задавайте `semanticLabel`.
